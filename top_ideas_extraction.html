🟢 TIER 1 — Transform the Core (Do Now)

1. Neural CDEs — Continuous-Time Event Processing UPGRADE HIGH

Current: _make_windows(window_size=86400) forces all events into fixed 1-day buckets. AIS pings (minutes) and SEC filings (quarters) are treated identically. Events within a window are simultaneous in the model's eyes.

💡 Neural Controlled Differential Equations integrate between irregular observations — the model learns dynamics from the shape of the event stream, not just snapshots. One model handles all 51+ sources regardless of sampling frequency. This is the single biggest architectural improvement possible — replaces the fundamental discretization error. Repo: patrick-kidger/NeuralCDE (NeurIPS'20 Spotlight)

→ Replace _make_windows() with CDE-based event integration. HeteroMemory update becomes a CDE solve. Start: wrap existing HGT convolution as CDEFunc; integrate from t=0 to t=as_of over the event stream.

2. Path Signatures — Universal Node Features from Rough Path Theory NEW MED

Current: 51+ bespoke per-source feature extractors feeding type_projections[ntype] = nn.Linear(in_dim, hidden_dim). No principled unified feature representation across domains.

💡 Path signatures are a provably universal feature map for any sequential path — invariant to time reparametrization, capturing area, curvature, and higher-order texture. One pipeline replaces 51 hand-crafted extractors. Particularly powerful for AIS vessel trajectories (path shape ≠ endpoint). Used in production at select quant funds, almost unknown in retail quant. Repo: kormilitzin/the-signature-method-in-machine-learning | library: signatory (PyTorch-native)

→ Install signatory. Compute truncated log-signatures (depth=3) for each entity's event stream. Add as additional input alongside existing features. New feature family: signature.{entity_type}.depth3 in GNNFeatureBuilder.

3. Splink Entity Resolution — Probabilistic Cross-Source Linking UPGRADE HIGH

Current: entities matched by exact entity_id strings. "Apple Inc.", "AAPL", "Apple Computer" across 51+ sources create separate fragmented nodes. Graph edges cannot form across name variants — this silently poisons every graph relationship.

💡 Splink (UK Ministry of Justice, 1.5k⭐) uses the Fellegi-Sunter probabilistic model to deduplicate records at national scale. Outputs match probability + confidence score per entity pair. Clean entity identity is the foundation of Palantir's platform. Expected improvement: 20-40% increase in effective graph connectivity. Repo: moj-analytical-services/splink

→ Build pre-ingestion EntityResolver. Match on company name, ISIN, LEI, MMSI/IMO for vessels. Output canonical entity IDs + confidence scores in a new entity_resolution table. All graph builders read canonical IDs.

4. Mamba/S4 — Replace HeteroMemory Fixed-Size Vectors UPGRADE HIGH

Current: HeteroMemory compresses each entity's entire history into a fixed memory_dim=64 vector. Years of entity history are forced through a 64-float bottleneck. Long-term patterns are structurally unreachable.

💡 Mamba's selective state space model has linear-time complexity and theoretically infinite effective context. Can encode years of entity history without O(n²) attention cost. For TirraMind — where a vessel's 3-year routing history predicts current behavior — this is transformative. Mamba-3 (15k⭐) outperforms Transformers on long-range dependencies at a fraction of compute. Repo: state-spaces/mamba

→ Replace HeteroMemory.update() GRU step with a per-node Mamba block processing the sequence of incoming message vectors. Start: small Mamba-2 block (d_model=64, d_state=16) as drop-in replacement.

5. TS2Vec — Contrastive Pretraining Across All 51+ Sources NEW MED

Current: GNN trains from scratch. No shared representation space across data domains. Cold-start problem for new entities with sparse history.

💡 TS2Vec (AAAI 2022, 800⭐) learns universal embeddings via hierarchical contrastive learning across timestamp and instance levels. Once pretrained, any time series maps to the same space. Enables: (1) cross-domain similarity search — "find entities behaving like this vessel", (2) transfer learning to scarce prediction tasks, (3) cold-start embeddings. Repo: zhihanyue/ts2vec

→ Pretrain TS2Vec on all time series in PipelineStore (no labels needed). Use learned encoder as initial node features for GNN. Add TS2VecFeatureBuilder. Fine-tune end-to-end.

🔵 TIER 2 — New Capabilities (Plan Next)

6. Neural Hawkes Process — Learned Event Timing Prediction UPGRADE MED

Current: ConvergenceDetector uses hand-coded causal templates for lead/lag identification. Template library is static and manually maintained.

💡 Hawkes processes model self-exciting events — one sanctions announcement excites vessel diversions, port closures, commodity moves over a learned decay. Neural Hawkes replaces the hand-coded template library with a fully learned causal event model. Directly answers: "probability of event X in next 3 days given observed stream" — a direct alpha signal. Repo: Hongrui24/NeuralHawkesPytorch

→ Train Neural Hawkes on TirraMind's convergence event history. Replace best_match() with Hawkes intensity predictions. Output per-event-type probabilities over next T hours.

7. Vine Copulas — Crisis-Aware Tail Dependence Edge Weights NEW MED

Current: graph edges from domain relationships and linear correlation. Linear correlation misses tail dependence — entities with low average correlation can co-crash violently during crises.

💡 Vine copulas model lower tail dependence (λ_L) — how strongly two entities co-crash. This is what institutional risk managers need and what correlation analysis misses entirely. Quarterly copula fits → tail dependence coefficients stored as crisis-weighted edge attributes. Repo: vinecopulib/pyvinecopulib (C++ backend, Python interface)

→ Add CopulaEdgeBuilder running quarterly. Bivariate copula fits for entity pairs with ≥180 days co-observations. Store λ_L, λ_U as edge attributes for HGT attention weighting.

8. Wasserstein Distribution Shift Detector — Data Quality + Regime Signal NEW LOW

Current: data quality tracked via staleness flags and manual quality scores on EngineeredFeature. No statistical test distinguishes API failure from regime change from model drift.

💡 Wasserstein distance (Earth Mover's Distance) measures distribution shifts with geometric meaning. Sinkhorn approximation is fast. Three use cases: (1) data quality alarm, (2) regime change signal, (3) prediction distribution drift detector. All three from identical infrastructure. Repo: PythonOT/POT (2.5k⭐)

→ Add WassersteinMonitor computing Sinkhorn distance between last 30-day and rolling 365-day baseline per data feed. Emit as wasserstein.{tool_name}.shift signal into ConvergenceDetector.

9. edgartools — 13F Holdings / 8-K Events / XBRL Financials UPGRADE LOW

Current: thin insider_filings.py and form144.py. 13F institutional holdings, 8-K material events, and XBRL financials not captured.

💡 13F → institution→stock edges (quarterly), 8-K → real-time material event signals, XBRL → structured balance sheet/income statement node features. Three of the richest public datasets in finance. edgartools handles all parsing, rate limiting, and XBRL extraction. MIT license, 1.5k⭐. Repo: dgunning/edgartools

→ Add agent/tools/edgar_filings.py. Three new observation types: institutional_holding, material_event, financial_statement. Register extractors in convergence/extractors.py.

10. GDN — Live Graph Structure Anomaly Detection NEW MED

Current: no monitoring of whether TirraMind's learned graph structure is still valid. A structurally changed relationship (company bankrupt, port closed) silently produces wrong predictions until next retrain.

💡 Graph Deviation Network learns expected inter-entity relationships, then flags structural deviations in real-time. GDN deviation scores are themselves early warning signals — a structural break often precedes a market event by days. Creates a self-monitoring world model that knows when it's wrong. Repo: KatieBuc/gnnad (GDN on PyG)

→ Train GDN on TirraMind's graph structure offline. Run in parallel with main GNN. Route deviation scores into ConvergenceDetector as graph_structure.{relation_type}.deviation signal category.

🟠 TIER 3 — Strategic Depth

11. HRP + Black-Litterman Portfolio Construction Layer UPGRADE MED

Current: return_pred_head produces raw return scalars. No translation into actual portfolio weights with risk budgeting.

💡 Black-Litterman takes GNN predictions as "views" with confidence = quality score. HRP uses hierarchical clustering — structurally identical to TirraMind's graph community structure. Together they produce institutionally acceptable portfolio weights with turnover constraints. Without this, TirraMind has no actionable financial output. Repos: PyPortfolioOpt (5k⭐), Riskfolio-Lib (3.5k⭐)

→ Add agent/portfolio/constructor.py. Input: return_pred_head outputs + quality scores. Output: weight vector with confidence intervals. Turnover constraint to prevent over-trading. Run weekly alongside GNN inference.

12. Barra-Style Signal Attribution — "Why Did This Prediction Happen?" NEW MED

Current: GNN produces return predictions but no attribution of which data sources drove the prediction. HGT attention weights are uncurated.

💡 Institutional investors demand attribution: "We're long copper because maritime signals contribute 62%, satellite 23%, macro 15%" is vastly more useful than a raw scalar. Enables rapid diagnosis of prediction errors. The existing AttentionCapturingHGTConv already captures the needed attention weights — they just need organizing into per-source contribution scores.

→ Aggregate HGT attention weights by source node type per prediction. Store as per-prediction factor decomposition in EngineeredFeature.source_signals. Add AttributionFeatureBuilder.

13. OpenMetadata — Data Governance for 51+ Sources UPGRADE MED

Current: data source metadata scattered across individual tool files. No central registry of freshness, schema, or lineage.

💡 OpenMetadata (6k⭐, Apache 2.0) tracks freshness, schema changes, column-level lineage, and quality tests. When a prediction unexpectedly changes, the catalog shows which upstream feed caused it. The difference between a research prototype and a production system. Repo: open-metadata/OpenMetadata

→ Deploy OpenMetadata via Docker. Register each tool in agent/tools/ as a data source. Add freshness SLAs. Wire existing source_signals lineage into catalog graph.

14. Satellite Imagery Economic Signals — Nightlights, Parking, Crops NEW HIGH

Current: satellite_activity.py monitors satellite orbits, not imagery. The physical-world observation layer is blind to what satellites actually see.

💡 Satellite imagery provides signals unavailable anywhere else: nightlight intensity (GDP proxy, 2-3 week lead time), industrial emissions (factory activity), parking lot fullness (retail traffic), crop NDVI (agricultural commodity prediction). These are the signals Renaissance Technologies uses. Open via Sentinel-2/Landsat.

→ Start with nightlight intensity (easiest) via VIIRS/DMSP. Build NightlightActivityTool monitoring 50 economic zones weekly. Add NDVI crop health for agricultural commodities.

🌙 MOONSHOTS — Highest Risk / Highest Reward

🌙 M1. Continuous-Time Heterogeneous World Model MOONSHOT RES

💡 Synthesize Ideas 1+2+4+6: Neural CDEs (continuous time) + Path Signatures (universal path features) + Mamba (long memory) + Neural Hawkes (event timing) = a fully continuous-time stochastic dynamical system on a heterogeneous graph. Formally: dX(t) = f(X(t), G(t))dt + g(X(t))dW(t). This doesn't exist in any open-source form. Each component is established; the synthesis is PhD-level novel. Build incrementally — each step is independently valuable.

🌙 M2. Self-Evolving Causal Graph MOONSHOT RES

💡 Synthesize Neural-GC (causal discovery) + Hawkes (event excitation) + GNN: a graph that discovers its own edges as data accumulates, models how discovered edges excite each other, and prunes edges when relationships decay. TirraMind's current graph topology is hand-defined and static. A self-evolving graph adapts to new markets, geopolitical configurations, and supply chains without human intervention. Repos: iancovert/Neural-GC + NeuralHawkesPytorch.

🌙 M3. Multi-Modal World State — Text + Graph + Imagery MOONSHOT RES

💡 FinGPT (text→structured events) + TirraMind GNN (structured graph) + Satellite CNN (visual economic signals) → unified world state via cross-modal attention fusion. Three orthogonal observation channels covering narrative, structural, and physical reality. The lead-lag structure across modalities is itself an alpha signal: text responds hours, graph days, imagery weeks. No open-source project has built this combination.
