Atomic Steps Roadmap

We decompose the M2 Options Pricing & Greeks phase into 5 atomic, independently testable steps:

M2.1: Implement BlackScholes European pricing model High
Write the BlackScholes class in agent/quant/options.py. Code must support call and put, continuous dividends (q), and vectorized operations on multiple dimensions. Add simple unit test validating pricing.
M2.2: Add analytical and autograd Greeks calculation High
Implement analytical_greeks and autograd_greeks (using torch.autograd.grad) for S, sigma, T, r. Add unit test checking that autograd gradients match analytical formulas to 1e-5.
M2.3: Implement vectorized implied volatility solver High
Write a differentiable, vectorized implied_volatility Newton-Raphson solver in PyTorch. Include checks to avoid division by zero or NaN gradients, clamping intermediate sigma updates. Add test for convergence and autograd flow.
M2.4: Implement Barone-Adesi Whaley American options pricing High
Write the BaroneAdesiWhaley class in PyTorch for American calls/puts. Include the iterative critical spot price (S*) search. Add tests confirming American prices are strictly >= European counterpart prices.
M2.5: Write comprehensive edge case test suites and run pytest High
Write tests/test_options.py covering edge cases (zero time-to-maturity, extremely low volatility, high dividends) and execute tests via pytest. Ensure clean passes and flawless autograd flows.
