1. Graph Neural Networks for Finance

These repos apply GNNs to financial data — the closest technical relatives to TirraMind's heterogeneous graph world model.

TongjiFinLab/THGNN ⭐ ~230

MIT License PyTorch CIKM 2022

Temporal and Heterogeneous Graph Neural Network for Financial Time Series Prediction. Models stocks as a dynamic heterogeneous graph where nodes are stocks and edges encode price correlations, sector relationships, and temporal dependencies. Uses a Heterogeneous Graph Attention Network (HeteGAT) with temporal encoding. Published at CIKM 2022.

🎯 TirraMind Take: Direct architectural parallel. THGNN's heterogeneous graph construction (price correlation + sector edges) mirrors TirraMind's multi-relational graph but is limited to stocks only. TirraMind extends this to vessels, commodities, countries, infrastructure — a superset. The temporal encoding mechanism and relation generation pipeline (generate_relation.py) are directly reusable patterns. The HeteGAT architecture could serve as a baseline to beat.

jwwthu/GNN4Fintech ⭐ ~350

Survey / Paper List Comprehensive

Curated collection of GNN papers for Financial Technology. Covers stock prediction (2016–2022), anti-money laundering, credit scoring, default prediction, financial event prediction, risk analysis, and fraud detection. The definitive literature map for GNN-in-finance.

🎯 TirraMind Take: Essential reference for positioning TirraMind's GNN against published work. Confirms that no existing paper combines all of TirraMind's data domains (maritime + satellite + supply chain + regulatory + prediction markets + infrastructure) into a single heterogeneous temporal graph. This is TirraMind's unique moat — and this repo proves it's genuinely novel.

timothewt/SP100AnalysisWithGNNs ⭐ ~30

PyTorch Geometric Temporal GNN

S&P100 stock analysis with GNNs. Builds graphs from sector membership and fundamental correlations. Uses PyG custom datasets and Temporal Graph Neural Networks for stock prediction. Practical, well-documented implementation.

🎯 TirraMind Take: Clean reference implementation for graph construction from fundamental data. The PyG custom dataset pattern is directly applicable to TirraMind's pipeline. Small but well-structured — good for studying how to productionize GNN-on-finance.

JunwenBai/correlation-gnn ⭐ ~15

PyTorch Research

Correlated Graph Neural Networks. Models label correlations as a multivariate Gaussian, learning the correlation structure in O(m) per optimization step. Addresses the problem of outcome correlation in GNN predictions.

🎯 TirraMind Take: The multivariate Gaussian correlation structure is relevant to TirraMind's fusion layer — when multiple assets/predictions are correlated, this approach provides a principled way to model joint uncertainty. Could improve the calibration of multi-asset predictions.

twitter-research/tgn ⭐ ~1,200

Apache 2.0 PyTorch ICML 2020

Temporal Graph Networks (TGN). The canonical framework for deep learning on dynamic graphs. Introduces a generic encoder architecture for graphs that evolve over time. Used by TirraMind's agent/models/gnn/het_tgn.py.

🎯 TirraMind Take: Already integrated into TirraMind's architecture. The upstream repo is worth monitoring for improvements, but the core contribution is already absorbed. Key insight: TGN's memory module + message function pattern is exactly what TirraMind needs for streaming graph updates from live data feeds.

pyg-team/pytorch_geometric ⭐ ~22,000

MIT License PyTorch Core Dependency

PyTorch Geometric (PyG). The primary GNN library. Includes TGN, HGT, GAT, and heterogeneous graph support. TirraMind's core GNN dependency.

🎯 TirraMind Take: Core dependency — already used. Key features to leverage more: PyG's HeteroData for multi-relational graphs, TemporalData for snapshots, and the new torch_geometric.nn.models.tgn module. Monitor PyG releases for heterogeneous temporal graph improvements.

2. Causal Discovery & Inference

TirraMind's architecture includes causal chain detection. These repos provide state-of-the-art methods for discovering causal structure in time series.

iancovert/Neural-GC ⭐ ~450

MIT License PyTorch TPAMI 2021

Neural Granger Causality. Uses neural networks (cMLP, cLSTM, cRNN) with sparse penalties on input weights to discover Granger causal relationships in multivariate time series. Group lasso, hierarchical, and group sparse group lasso penalties. Proximal gradient descent (ISTA) for optimization.

🎯 TirraMind Take: Directly applicable to TirraMind's causal discovery layer. The cLSTM/cRNN models could replace or augment TirraMind's current Granger causality approach. The sparse penalty mechanism is elegant — it discovers causal structure as a byproduct of prediction, not as a separate step. Could be integrated into agent/discovery/ or the convergence module. Key limitation: assumes all time series are at same frequency — would need adaptation for TirraMind's mixed-frequency data (daily prices + hourly AIS + quarterly filings).

M-Nauta/TCDF ⭐ ~280

MIT License PyTorch CNN-based

Temporal Causal Discovery Framework. Uses CNNs with attention to discover causal relationships AND time delays between time series. Plots temporal causal graphs. Unlike Neural-GC, TCDF explicitly discovers time delay between cause and effect — critical for financial applications where lead-lag relationships matter.

🎯 TirraMind Take: The time-delay discovery is uniquely valuable for TirraMind. Knowing that AIS vessel movements lead commodity prices by 3 days (not just "are correlated") is actionable. TCDF's CNN attention mechanism could complement Neural-GC's sparse penalties. Both should be evaluated as causal discovery backends for agent/convergence/.

tcassou/causal_impact ⭐ ~400

MIT License Python BSTS

Python port of Google's CausalImpact R package. Uses Bayesian structural time-series models to estimate the causal effect of an intervention on a time series. Builds a synthetic counterfactual from control time series.

🎯 TirraMind Take: Useful for event studies — e.g., "what was the causal impact of the Red Sea shipping disruption on European energy prices?" The counterfactual construction is a natural complement to TirraMind's event detection. Could be used to validate GNN-predicted causal edges with a Bayesian method.

wwrechard/pydlm ⭐ ~500

BSD License Python

Bayesian dynamic linear model library. Based on Harrison & West (1999). Optimized for fast model fitting and inference. Supports trend, seasonality, and dynamic regression components.

🎯 TirraMind Take: Could serve as a lightweight Bayesian layer for time series components that don't need full GNN treatment. The dynamic regression component is particularly useful — it allows regression coefficients to evolve over time, which matches how financial relationships change across regimes.

3. Alternative Data & OSINT Platforms

These repos aggregate non-traditional data sources — the "unique observation" layer that gives TirraMind its edge.

simplifaisoul/osiris ⭐ ~1,900

MIT License Next.js / MapLibre GL OSINT Dashboard

OSIRIS — Open Source Intelligence & Reconnaissance Integrated System. Real-time global intelligence dashboard with 15 data layers (flights, maritime, earthquakes, wildfires, satellites, CCTV, news, conflict zones). GPU-accelerated WebGL rendering. RECON toolkit for cyber intelligence. Positioned as a Palantir alternative. Full analysis in separate doc: osiris_research.html.

🎯 TirraMind Take: (1) New data adapters for flights, wildfires, CCTV, conflict zones. (2) MapLibre GL visualization frontend for TirraMind's world model. (3) RECON toolkit patterns for infrastructure monitoring enrichment. (4) Viewport-aware loading and aggressive caching patterns for the pipeline.

atlas-bear/osint-tools ⭐ ~200

MIT License Curated List Maritime + Supply Chain

Maritime and supply chain OSINT tools. Comprehensive directory of ship tracking, container/cargo tracking, geolocation, supply chain risk management, maritime data/analysis, vessel registration, maritime infrastructure, and crew management tools.

🎯 TirraMind Take: Goldmine for expanding agent/tools/ais_vessel.py. Lists dozens of data sources beyond AIS: port congestion APIs, container tracking, maritime infrastructure databases, crew change monitoring. Many are free/public. Could double TirraMind's maritime data coverage. The supply chain risk management section directly maps to TirraMind's supply chain disruption prediction use case.

SpaceNetLab/satellite-image-deep-learning ⭐ ~9,000

Resource List Satellite + Deep Learning

Comprehensive resource list for satellite image deep learning. Covers techniques for predicting economic activity, poverty, crop yields, and infrastructure changes from satellite imagery. Links to datasets, models, and papers.

🎯 TirraMind Take: TirraMind's satellite_activity.py currently focuses on satellite orbits/activity, not imagery analysis. This repo opens the door to satellite imagery as a direct economic signal — nightlight intensity for GDP nowcasting, parking lot fullness for retail activity, crop health for agricultural commodity prediction. A major expansion opportunity for the surveillance layer.

dgunning/edgartools ⭐ ~1,500

MIT License Python SEC Filings

The only open-source toolkit for SEC EDGAR. Supports all SEC form types: 10-K, 10-Q, 8-K, 13F (institutional holdings), Form 4 (insider transactions), proxy statements, S-1, N-CSR, N-PORT. Extracts both text and XBRL-structured financial data.

🎯 TirraMind Take: TirraMind has insider_filings.py and form144.py but lacks comprehensive SEC filing extraction. EdgarTools could replace/supplement these with richer data: 13F institutional holdings as graph edges (institution → stock), 8-K event detection for real-time material event signals, XBRL financials as node features. High-value, low-effort integration.

4. Financial LLMs & NLP

LLMs fine-tuned for financial text — sentiment, event extraction, and narrative understanding from unstructured data.

AI4Finance-Foundation/FinGPT ⭐ ~15,000

MIT License Python / PyTorch LLM + Finance

Open-Source Financial Large Language Models. Full-stack framework with 5 layers: data source, data engineering, LLMs, task, and application. Covers sentiment analysis, financial news classification, market prediction, and robo-advisor. Instruction-tuned on financial data. 92% F1 on financial text classification.

🎯 TirraMind Take: FinGPT's sentiment and event extraction could feed into TirraMind's graph as text-derived edges and node features. For example: FinGPT detects "supply chain disruption" in a 10-Q → creates a RISK edge in TirraMind's graph. The data source layer's real-time news capture is also valuable. However, FinGPT is LLM-centric; TirraMind's edge is in structured heterogeneous data. The two are complementary — FinGPT for unstructured → structured conversion, TirraMind for structured → prediction.

stefanoamorelli/sec-edgar-toolkit ⭐ ~200

Python / TypeScript SEC EDGAR

Modern, type-safe, multi-language SEC EDGAR toolkit. Alternative to edgartools with TypeScript support. Focuses on modern API design.

🎯 TirraMind Take: Secondary option to edgartools. The TypeScript support is less relevant since TirraMind is Python. Prefer edgartools for Python-native integration.

5. Bayesian & State Space Models

TirraMind uses Bayesian belief propagation and Kalman signal fusion. These repos provide production-grade implementations.

Focus/bsts ⭐ ~200

Python Bayesian

Bayesian structural time series in Python. Variation on "Bayesian Variable Selection for Nowcasting Economic Time Series" (Scott & Varian). Includes spike-and-slab priors for variable selection — automatically chooses which predictors matter.

🎯 TirraMind Take: The spike-and-slab prior for automatic predictor selection is directly applicable to TirraMind's feature engineering. With 51+ data sources, knowing which ones actually predict a given target is crucial. BSTS provides a principled Bayesian approach. Could serve as a lightweight nowcasting layer alongside the heavier GNN.

rlabbe/Kalman-and-Bayesian-Filters-in-Python ⭐ ~17,000

Jupyter Book Educational + Practical

The definitive Kalman filter resource. Jupyter notebooks covering Kalman filters, extended KF, unscented KF, particle filters, and sensor fusion. Focuses on intuition, not proofs. All exercises include solutions.

🎯 TirraMind Take: Reference implementation for TirraMind's Kalman signal fusion layer. The sensor fusion chapters are directly applicable to combining signals from multiple data sources (e.g., fusing AIS vessel speed + satellite position + port authority schedule into a single vessel ETA estimate). The particle filter section is relevant for non-Gaussian financial distributions.

henryzhangzhy/pykffusion ⭐ ~50

Python Multi-Sensor Fusion

Multi-sensor fusion with Kalman filters. Python implementation of multi-sensor Kalman filter fusion for object detection and tracking in urban driving environments.

🎯 TirraMind Take: The multi-sensor fusion pattern is analogous to TirraMind's multi-source signal fusion. Tracking a "financial object" (e.g., a commodity shipment) across multiple data sources (AIS → port camera → trucking data → warehouse inventory) is structurally identical to tracking a physical object across sensors. The fusion architecture is reusable.

6. Prediction Markets & Crowd Intelligence

Prediction markets aggregate dispersed knowledge into probabilities. TirraMind already ingests Polymarket data — these repos extend that capability.

Jon-Becker/prediction-market-analysis ⭐ ~400

MIT License Python Polymarket + Kalshi

Largest publicly available dataset of Polymarket and Kalshi data. 36 GiB compressed dataset. Collects market metadata, trade history via API and blockchain. Parquet-based storage with automatic progress saving. Extensible analysis framework.

🎯 TirraMind Take: TirraMind has polymarket.py and polymarket_whales.py but this repo provides a much richer historical dataset (36 GiB) and blockchain-level trade data. Could significantly deepen TirraMind's prediction market signals. The trade-level data enables whale detection, informed trader identification, and market efficiency analysis — all valuable graph features.

b1rdmania/polymarket-ai-trading ⭐ ~150

MIT License Python AI Trading

AI-powered trading system for Polymarket. Built on 40+ years of research. Uses mean reversion, GPT-4o analysis, and multi-model paper trading. Live dashboard at vercel.app.

🎯 TirraMind Take: The mean reversion + LLM analysis combination is interesting — LLMs extract narrative from news, mean reversion provides the statistical edge. TirraMind could adopt a similar pattern: GNN provides the structural prediction, LLM provides narrative context, and the two are fused. The paper trading dashboard is a good reference for TirraMind's own backtesting UI.

aarora4/Awesome-Prediction-Market-Tools ⭐ ~200

Curated List Prediction Markets

Curated list of prediction market tools. Includes PolyIntel (whale detection Telegram bot), Polytrackerbot (Twitter bot), and various analysis tools. Covers Polymarket, Kalshi, Metaculus, Manifold Markets.

🎯 TirraMind Take: Directory of tools and data sources beyond Polymarket. Metaculus and Manifold Markets provide different crowd structures (continuous vs binary, different user bases) — aggregating across platforms could improve signal quality. The whale detection tools validate TirraMind's existing polymarket_whales.py approach.

7. Anomaly & Regime Detection

Detecting when market behavior changes is critical for avoiding prediction in wrong regimes.

Fengrui-Liu/StreamAD ⭐ ~150

MIT License Python Online / Streaming

Online anomaly detection for data streams. Detectors process univariate or multivariate time series in real-time. Includes statistical, ML, and deep learning methods. Designed for streaming environments.

🎯 TirraMind Take: TirraMind's pipeline processes streaming data from 51+ sources. StreamAD's online detectors could identify when a data feed goes anomalous (API failure, regime change, data quality issue) before it corrupts the GNN training. The streaming architecture matches TirraMind's real-time ingestion pattern.

Sakeeb91/market-regime-detection ⭐ ~100

Python HMM

Market regime detection with Hidden Markov Models. Identifies bull, bear, and high-volatility states. Adapts investment strategies accordingly. Clean, well-structured implementation.

🎯 TirraMind Take: TirraMind has agent/pipeline/regime_gate.py — this repo provides a cleaner HMM implementation that could replace or augment the current regime detection. The strategy adaptation pattern (different behavior in different regimes) is exactly what TirraMind's regime gate should do: suppress predictions in regimes where the model has no edge.

rob-med/awesome-TS-anomaly-detection ⭐ ~3,500

Curated List Time Series Anomaly

Comprehensive list of time series anomaly detection tools. Includes ruptures (change point detection), Skyline (real-time anomaly monitoring), NAB (benchmark), and dozens of papers and libraries.

🎯 TirraMind Take: The ruptures library for offline change point detection is particularly relevant — it could identify structural breaks in financial relationships that signal when to retrain the GNN. Skyline's real-time monitoring architecture is a reference for TirraMind's own data quality monitoring.

8. Supply Chain & Physical-World AI

TirraMind's Layer 0 (physical reality) includes supply chain monitoring. These repos model physical flows with AI.

AquarlisPrime/AI-Driven-Forecast-Resilience-Simulator ⭐ ~50

Python / Streamlit Supply Chain Digital Twin

AI-driven supply chain resilience simulator. Models complex supply networks, predicts demand, runs disruption scenarios, visualizes downstream risks, and performs cost-emissions-risk tradeoffs. Interactive Streamlit interface.

🎯 TirraMind Take: The disruption scenario simulation is directly relevant — it shows what happens when a node (port, factory, shipping lane) fails. TirraMind's graph could feed into such a simulator: GNN predicts disruption probability → simulator estimates downstream impact → combined signal for trading. The Streamlit interface is a good reference for TirraMind's own visualization.

igetint3000/ChaosChain-AI ⭐ ~20

Python Monte Carlo + Chaos

ChaosChain-AI — supply chain simulator with chaotic demand modeling. Combines chaotic demand models with Monte Carlo simulations. Real-time monitoring and predictive analytics.

🎯 TirraMind Take: The chaotic demand modeling is interesting — financial markets exhibit chaotic behavior, and methods for modeling chaotic supply chains may transfer to modeling chaotic price dynamics. Niche but conceptually valuable.

9. Quantitative Finance Platforms & Curated Lists

Meta-resources that map the broader quant finance open-source landscape.

firmai/financial-machine-learning ⭐ ~7,000

Curated List Comprehensive

Curated list of practical financial ML tools. Covers trading (deep learning, RL, other models, data processing), portfolio management (selection, optimization, factor/risk analysis), techniques (unsupervised, textual), derivatives, fixed income, and alternative finance. Extensive wiki.

🎯 TirraMind Take: The "Alternative Finance" section is most relevant — it covers non-traditional data sources and methods. The data processing techniques section has useful patterns for financial time series. Overall, this list confirms TirraMind's positioning: most tools focus on price/volume data; almost none combine physical-world data (maritime, satellite, supply chain) with financial data in a GNN.

wilsonfreitas/awesome-quant ⭐ ~19,000

Curated List Comprehensive Quant

The definitive curated list of quantitative finance. Covers data sources, trading frameworks, backtesting, risk management, derivatives pricing, and more. 19k stars — the standard reference.

🎯 TirraMind Take: Essential reference for the broader quant ecosystem. The data sources section lists APIs and datasets TirraMind may not yet cover. The backtesting frameworks section is useful for building TirraMind's strategy evaluation layer. Confirms that most quant tools are price-data-centric — TirraMind's alternative data focus is genuinely differentiated.

nautechsystems/nautilus_trader ⭐ ~4,500

Rust + Python Production Trading

Production-grade, Rust-native event-driven trading framework. Spans research, deterministic simulation, and live execution. Python for control, Rust for performance. High-frequency capable.

🎯 TirraMind Take: If/when TirraMind moves from prediction to execution, NautilusTrader is the leading open-source execution framework. Its event-driven architecture and deterministic simulation are gold-standard. For now, it's aspirational — TirraMind should focus on prediction quality first. But the architecture is worth studying for the pipeline design.

10. Synthesis: Top Ideas for TirraMind

🥇 Tier 1 — High Impact, Low Effort (Do Now)

  1. Integrate edgartools for SEC filing extraction → replace/augment insider_filings.py and form144.py with 13F holdings, 8-K events, XBRL financials as graph features.
  2. Adopt Neural-GC or TCDF as causal discovery backends → replace or augment current Granger causality in agent/convergence/. TCDF's time-delay discovery is uniquely valuable.
  3. Mine atlas-bear/osint-tools for new maritime/supply chain data sources → expand ais_vessel.py with port congestion, container tracking, crew change data.
  4. Adopt OSIRIS's viewport-aware loading + layerFetchedRef caching → reduce pipeline API calls by 60-80%.

🥈 Tier 2 — High Impact, Medium Effort (Plan Next)

  1. Build a MapLibre GL visualization frontend for TirraMind's world model → render entity nodes, edge relationships, attention weights, and conflict zones on a GPU-accelerated map. Borrow OSIRIS's architecture.
  2. Integrate Jon-Becker/prediction-market-analysis dataset (36 GiB) → deepen Polymarket signals with blockchain-level trade data and cross-platform aggregation (Kalshi, Metaculus).
  3. Add satellite imagery analysis capability → nightlight intensity for GDP nowcasting, crop health for agricultural commodities, parking lot analysis for retail. Use satellite-image-deep-learning as reference.
  4. Implement BSTS spike-and-slab nowcasting → lightweight Bayesian layer for automatic predictor selection across 51+ data sources.

🥉 Tier 3 — Strategic, Longer-Term (Research & Evaluate)

  1. Evaluate FinGPT for unstructured→structured conversion → LLM extracts events/sentiment from news/filings → feeds into TirraMind's graph as edges and node features.
  2. Study THGNN as a baseline → implement their HeteGAT architecture on TirraMind's data to establish a published-method baseline. TirraMind should beat it given richer data.
  3. Adopt StreamAD for data quality monitoring → detect anomalous data feeds before they corrupt GNN training.
  4. Study NautilusTrader architecture for future execution layer → event-driven design, deterministic simulation, Rust performance.
  5. Build supply chain disruption simulator → GNN predicts disruption probability → simulator estimates downstream impact → combined trading signal.

Key Insight: TirraMind's Moat Is Real

After surveying 20+ open-source repos across GNN-for-finance, alternative data, causal discovery, and quant platforms, one finding stands out:

No existing open-source project combines all of TirraMind's data domains into a single heterogeneous temporal graph.

  • THGNN does heterogeneous GNN on stocks only — no maritime, no satellite, no supply chain, no regulatory.
  • OSIRIS does real-time OSINT visualization — but no prediction, no graph learning, no causal discovery.
  • FinGPT does financial NLP — but no structured heterogeneous data fusion.
  • Neural-GC/TCDF do causal discovery — but on homogeneous time series, not heterogeneous graphs.
  • Prediction market tools analyze crowd probabilities — but don't fuse them with physical-world data.

The integration of 51+ heterogeneous data sources × temporal GNN × Bayesian fusion × causal discovery × continuous learning is genuinely novel in the open-source landscape. The individual components exist. The integration does not.

This is TirraMind's moat. Build it.
