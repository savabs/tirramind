# Raw Sources

Store immutable source material for future wiki ingests here when the source does not already live elsewhere in the repository.

Rules:

- Treat files in this directory as read-only once added.
- Prefer markdown, plain text, images, and other directly inspectable formats.
- Reference raw files from wiki page frontmatter via `source_docs`.
- If the source already exists elsewhere in the repo, cite that path instead of duplicating it here.
