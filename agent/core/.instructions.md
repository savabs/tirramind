# Core Module Conventions

## Architecture
The orchestrator is the **Agent Layer execution engine**: Research → Plan → Execute → Synthesize.

## Key Classes
- `Orchestrator` — main pipeline: takes a user query, runs the 4-phase loop
- Tool registry, memory integration, LLM client coordination

## Conventions
- `from __future__ import annotations` at top.
- The orchestrator calls tools and LLM — it does not contain math or data fetching logic.
- All tool calls go through the registered tool interface, never direct imports.
- Memory (episodic, semantic, working) is injected, not globally accessed.
- LLM is **support role only** — it generates hypotheses and narrates results. It never makes trading decisions.

## Error Handling
- Tool failures are caught and reported, never crash the orchestrator.
- LLM failures trigger graceful degradation (return partial results, log the error).
- Timeout all external calls.

## Testing
- Mock LLM responses and tool results.
- Test the orchestration flow, not individual tool/LLM behavior.

## Layer Rule
This is the **Agent Layer controller**. It coordinates Layers 1-7 but contains no layer-specific logic itself.
