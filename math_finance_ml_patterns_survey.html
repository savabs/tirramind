📐 TRACK A — Pure Mathematical Finance

A.1 Stochastic Calculus, PDE Methods & Lévy Processes

cantaro86/Financial-Models-Numerical-Methods ⭐ 6,000

Python/Jupyter Math Finance

Comprehensive notebooks: SDEs, Lévy processes, PDE methods (finite difference), Fourier pricing (COS, Carr-Madan), Kalman filter, Heston calibration. Covers topics "not popular among practitioners" — the advanced math that gives an edge.

🎯 TirraMind: The Lévy process and Fourier pricing notebooks are reference implementations for modeling assets with jumps — critical for capturing tail events. The PDE finite-difference methods could model how shocks propagate through TirraMind's entity graph as a diffusion process.

patrick-t98/quantitative-finance-notebooks ⭐ 300

Python SDE + Greeks

Itô-Doeblin formula, GBM, Black-Scholes-Merton, Greeks, jump processes, exotic/American options. Clean pedagogical implementations.

🎯 TirraMind: The jump process implementations complement cantaro86's work. Jump-diffusion models are essential for modeling sudden regime changes — exactly what TirraMind's alternative data (sanctions, disasters, port closures) detects.

Apress/Stochastic-Finance-with-Python ⭐ 50

Python Stochastic Finance

Companion code for "Stochastic Finance with Python" (Avishek Nag, 2024). Covers stochastic processes, option pricing, Monte Carlo methods.

🎯 TirraMind: Modern textbook-quality reference for stochastic finance implementations. The Monte Carlo methods are directly applicable to TirraMind's scenario simulation layer.

A.2 Rough Volatility & Fractional Processes

ryanmccrickerd/rough_bergomi ⭐ 200

Python Rough Bergomi

Python implementation of the rough Bergomi (rBergomi) model by Bayer, Friz & Gatheral. Uses hybrid simulation scheme (Bennedsen, Lunde, Pakkanen) and variance reduction pricing (McCrickerd & Pakkanen).

🎯 TirraMind: Rough volatility (H < 0.5) is a cutting-edge discovery — volatility is rougher than Brownian motion, implying strong short-term predictability. TirraMind's high-frequency alternative data (AIS, satellite) could feed into rough vol models for unprecedented short-horizon edge.

sigurdroemer/rough_volatility ⭐ 30

Python Rough Vol + NN

Pricing models and neural network representations for rough vs classical stochastic volatility. Empirical analysis on SPX and VIX markets.

🎯 TirraMind: The neural network + rough vol combination is directly relevant — it shows how to embed advanced math models into neural architectures. TirraMind could embed rough vol dynamics into its GNN node update functions.

A.3 Optimal Transport & Wasserstein Methods

PythonOT/POT ⭐ 2,500

Python Optimal Transport

Python Optimal Transport library. Wasserstein distance, Sinkhorn, Gromov-Wasserstein, barycenters, domain adaptation, Wasserstein dimensionality reduction. 31 releases. The standard OT library.

🎯 TirraMind: Wasserstein distances can measure distribution shifts in TirraMind's data feeds — detecting when a data source's statistical properties change (regime shift). Distributionally robust portfolio optimization via Wasserstein ambiguity sets is a direct application. Domain adaptation can align embeddings from different data sources.

A.4 Copulas & Dependence Modeling

vinecopulib/pyvinecopulib ⭐ 200

Python/C++ Vine Copulas

High-performance vine copula library. C++ backend (Eigen) with Python interface. Flexible dependence modeling via bivariate building blocks (Aas et al., 2009).

🎯 TirraMind: Vine copulas model complex multivariate dependence structures — exactly what TirraMind needs to understand how 51+ data sources co-move during crises. Tail dependence coefficients from copulas can become edge weights in TirraMind's graph, encoding "these entities crash together."

maximenc/pycop ⭐ 100

Python Copula Library

Multivariate dependence modeling with copulas. Estimation, simulation, mixture models, empirical copula methods, non-parametric tail dependence.

🎯 TirraMind: The mixture copula approach allows blending different dependence structures — useful for modeling assets that behave differently in normal vs crisis regimes. Lighter-weight alternative to pyvinecopulib for simpler use cases.

A.5 Path Signatures (Rough Path Theory)

kormilitzin/the-signature-method-in-machine-learning ⭐ 300

Python Path Signatures

Theory and practice of the signature method — a powerful feature extraction technique from rough path theory in stochastic analysis. Applications in finance, medicine, and deep learning.

🎯 TirraMind: Path signatures are a universal feature extractor for sequential data — they capture the "shape" of a time series path (lead-lag, area, curvature). TirraMind could compute signatures of AIS vessel trajectories, commodity price paths, or satellite activity sequences as graph node features. This is genuinely cutting-edge — few quant funds use signatures yet.

🧠 TRACK B — Advanced ML Pattern Recognition

B.1 Time Series Foundation Models

google-research/timesfm ⭐ 4,000

Python Google Research

TimesFM — pretrained time-series foundation model by Google. Decoder-only architecture. Fine-tuning with LoRA via HuggingFace + PEFT. Probabilistic forecasting.

🎯 TirraMind: TimesFM could serve as a baseline forecaster for individual time series in TirraMind's graph. The GNN would then model cross-entity interactions on top. The LoRA fine-tuning approach allows adapting to TirraMind's unique data without full retraining.

time-series-foundation-models/lag-llama ⭐ 1,500

Python Foundation Model

Lag-Llama — probabilistic time series foundation model. Outputs full probability distributions per timestep. Pretrained on diverse corpus. Supports finetuning.

🎯 TirraMind: The probabilistic output is key — it provides uncertainty estimates that TirraMind's Bayesian fusion layer can ingest. Lag-Llama on individual series + GNN on cross-series interactions = powerful combination.

B.2 State Space Models (S4 / Mamba)

state-spaces/mamba ⭐ 15,000

Python SSM Architecture

Mamba — structured state space model architecture. Linear-time sequence modeling, outperforming Transformers on long sequences. Mamba-3 with structured state space duality.

🎯 TirraMind: Mamba could replace or augment TGN for temporal sequence modeling in TirraMind's graph. Its linear-time scaling is critical for processing long histories (years of daily data across thousands of entities). The state space formulation naturally handles irregular sampling — common in alternative data.

state-spaces/s4 ⭐ 3,000

Python S4 Model

Structured State Space Sequence Models (S4). The predecessor to Mamba. Handles Long Range Arena tasks, speech, and time series. Mathematical foundation for modern SSMs.

🎯 TirraMind: S4's mathematical formulation (HiPPO matrices, bilinear discretization) is worth studying for TirraMind's temporal encoding layer. The continuous-time formulation connects naturally to neural ODEs and stochastic calculus.

B.3 Contrastive & Self-Supervised Learning for Time Series

zhihanyue/ts2vec ⭐ 800

Python AAAI 2022

TS2Vec — universal time series representation learning. Contrastive learning over timestamp-level and instance-level views. Hierarchical contrasting. Works on any time series length.

🎯 TirraMind: TS2Vec could generate universal embeddings for any time series in TirraMind's graph — AIS, prices, satellite, news sentiment — all mapped to the same representation space. This enables cross-domain similarity search: "find all entities whose time series patterns resemble this vessel's trajectory."

emadeldeen24/TS-TCC ⭐ 600

Python IJCAI 2021

Time-Series Representation Learning via Temporal and Contextual Contrasting. Weak and strong augmentations. Temporal contrasting module + contextual contrasting module.

🎯 TirraMind: The augmentation-based contrastive approach is robust to noise — important for TirraMind's noisy alternative data. The contextual contrasting (discriminating between different entities' patterns) maps directly to TirraMind's entity resolution problem.

qingsongedu/Awesome-SSL4TS ⭐ 800

Curated List SSL for TS

Comprehensive survey of self-supervised learning for time series. Covers contrastive, generative, and predictive SSL methods. The definitive reference.

🎯 TirraMind: Essential reference for choosing SSL methods. The contrastive methods are most relevant — they can pretrain TirraMind's encoders on unlabeled alternative data before fine-tuning on specific prediction tasks.

B.4 Neural Differential Equations

patrick-kidger/NeuralCDE ⭐ 700

Python NeurIPS 2020 Spotlight

Neural Controlled Differential Equations for irregular time series. Handles partially-observed, irregularly-sampled multivariate data. Continuous-time analogue of RNNs. torchcde + torchdiffeq.

🎯 TirraMind: TirraMind's data is inherently irregularly sampled — AIS pings every few minutes, SEC filings quarterly, satellite images when clouds permit. Neural CDEs handle this natively. This is a direct architectural upgrade over discrete-time GNN snapshots. The CDE formulation also connects to path signatures mathematically.

Zymrael/awesome-neural-ode ⭐ 1,000

Curated List Neural ODEs

Comprehensive collection of neural ODE/CDE/SDE resources. Papers, code, tutorials. Covers continuous normalizing flows, latent ODEs, and applications.

🎯 TirraMind: The neural SDE section is particularly relevant — it combines stochastic calculus with deep learning. Neural SDEs could model TirraMind's entity states as stochastic processes, with the GNN providing the drift and diffusion functions.

B.5 Topological Data Analysis

giotto-ai/giotto-tda ⭐ 800

Python TDA Library

High-performance topological ML toolbox. Persistent homology, Mapper algorithm, persistence diagram vectorization. scikit-learn compatible. Time series, graphs, images, point clouds.

🎯 TirraMind: Persistent homology detects topological features (loops, voids) in data that persist across scales — capturing market regime structure invisible to correlation analysis. The Mapper algorithm can create a topological graph from TirraMind's entity embeddings, revealing the "shape" of the market. This is bleeding-edge — almost no quant funds use TDA.

B.6 Hawkes Processes & Point Processes

slinderman/pyhawkes ⭐ 200

Python Hawkes Process

Bayesian inference for Hawkes processes with random network models. Discovers latent network connections from event timing patterns.

🎯 TirraMind: Hawkes processes model self-exciting events — exactly what financial dislocations look like (one default triggers another). TirraMind could model sanctions events, port closures, or price jumps as mutually exciting point processes. The inferred network from pyhawkes could become edges in TirraMind's graph.

Hongrui24/NeuralHawkesPytorch ⭐ 100

Python/PyTorch Neural Hawkes

Neural Hawkes process — deep learning for event prediction. Predicts when the next event happens and what type. LSTM-based intensity functions.

🎯 TirraMind: Neural Hawkes can predict the timing and type of future events in TirraMind's data streams — when will the next sanctions announcement occur? What type? This adds a temporal point process layer on top of the GNN's continuous predictions.

B.7 Graph Anomaly Detection

🎯 TirraMind: GDN's learned graph structure mirrors TirraMind's approach. The deviation scoring could detect when TirraMind's entity relationships break down — a supply chain link that suddenly deviates from historical patterns. This is an early warning system for the graph itself.

Deep learning outlier/anomaly detection library. Transformer-based, autoencoder-based, GAN-based detectors. Tabular and time series data.

🎯 TirraMind: DeepOD's transformer-based anomaly detectors could monitor each of TirraMind's 51+ data feeds for anomalies — detecting data quality issues, API failures, or genuine regime changes before they corrupt the GNN training pipeline.

B.8 Manifold Learning & Dimensionality Reduction

Uniform Manifold Approximation and Projection. Fast, scalable dimensionality reduction. Preserves both local and global structure. Beyond t-SNE.

  3. Mamba/S4 — linear-time sequence modeling for long entity histories.
  4. Topological Data Analysis (giotto-tda) — persistent homology for market regime structure. Bleeding-edge.
  5. Neural Hawkes Processes — predict timing/type of future events from event stream data.
  6. GDN (Graph Deviation Network) — anomaly detection on the graph itself. Early warning system.
