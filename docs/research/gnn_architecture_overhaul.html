Research: GNN Architecture Overhaul — Post-V72 Pivot

Date: 2026-06-07  |  Status: Active  |  Trigger: [[checkpoint_2026-06-07_v72_architecture_handoff]]

Problem

After 72 Kaggle kernel versions, the HetTGN + ListNet + concat-head MTL stack cannot pass the Phase 41b gate (IC > 0.03 and t > 2.0). V72 confirmatory run with aligned eval: ConcatReturnHead IC=+0.0587, t=1.03 — directionally positive, statistically weak. Hyperparameter tuning on this stack is exhausted.

What V65–V72 proved (stop re-litigating)

  • Fixed: clamp saturation (return_pred_clamp=50 + BatchNorm), eval/training mismatch (load_model concat restore)
  • Refuted: ListNet τ=0.5, PCGrad as improvement
  • Ceiling: current MTL stack tops out ~IC +0.06, t ~1.0 on smoke folds
  • Still open: H1 backfill label shift — V52 (+0.0474) may be partly leakage-era

Architectural flaws (structural, not tunable)

  1. MTL gradient warfare — obs_type (~2145 entities) vs return (~53 instruments) share one backbone
  2. Wrong coupling — concat head can satisfy return loss via raw features alone, starving backbone
  3. CSRC instability — noisy decile pairs in non-stationary returns drive collapse
  4. TGN inductive bias — event-prediction architecture applied to cross-sectional ranking
  5. Eval inconsistency — trained heads vs PurgedRanker (honest Ridge) disagree; PurgedRanker negative post-backfill

Overhaul plan (two phases)

Phase A — Honest baselines (Option A, 1–2 days)

Answer: is there learnable signal in post-backfill labels before building new architecture?

Decision tree:

  • All baselines IC ≈ 0 → fix data/labels (H1) before architecture work
  • RawPrice passes gate, GNN does not → graph encoder not adding value; proceed to decoupled Stage-B ranker
  • Both pass → two-stage pipeline (Option B) is the path

Phase B — Decoupled two-stage (Option B, if Phase A shows signal)

  1. Stage 1: Train HetTGN self-supervised only (obs_type + link + time_delta). No return loss, no CSRC.
  2. Stage 2: Export instrument embeddings per window → separate cross-sectional ranker (Ridge, RankNet, or small MLP).

References: THGNN (CIKM 2022), MDGNN (AAAI 2024) — production quant GNNs separate representation from prediction.

Phase C — Surgical alternatives (if B insufficient)

  • Replace ListNet with pairwise RankNet loss
  • Direction classification instead of forward-return regression
  • New backbone (temporal transformer over entity-obs sequences — Phase 48 direction)

Exit gate (unchanged)

Mean IC > 0.03 and t-stat > 2.0 on purged walk-forward. Primary strategy: RawPrice-PurgedRanker for Phase A; Stage2-Ranker for Phase B.
