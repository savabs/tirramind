V61 Training Efficiency Solution

Research Date: 2026-06-06

Problem: V60 showed increased embedding collapse (48.4% vs 23.2% in V58) and flat return loss despite VICReg at 0.25 weight. PurgedRanker IC was negative (-0.0440), far below the V52 baseline (+0.0474).

Root Causes Identified:

  1. Loss Scale Imbalance: Value loss (1653) dominates return loss (210), creating massive gradient imbalance
  2. VICReg Insufficient: 0.25 weight is too low; Euclidean-based regularization alone is weak
  3. No Anti-Collapse Normalization: Missing proven GNN collapse prevention layers (PairNorm/ContraNorm)
  4. Gradient Conflicts: Different tasks (value, return, obs_type) pull in conflicting directions

1. Research Summary

1.1 GNN Embedding Collapse Prevention (State-of-the-Art 2026)

Key Papers:
  • ContraNorm (Guo et al. 2023, PKU): Addresses dimensional collapse (embeddings in narrow cone) via contrastive uniformity loss → normalization layer
  • PairNorm (Zhao & Akoglu 2020): Prevents embeddings from becoming too similar by maintaining pairwise distances
  • Laplacian-LoRA (2026): Low-rank spectral adaptation delays oversmoothing by weakening per-layer contraction

ContraNorm is optimal for our case because:

  • Directly targets dimensional collapse (the problem in V60: 48% collapse, effective rank 3.0/93)
  • Zero-parameter overhead (vs VICReg's additional loss term)
  • Proven effective in financial GNNs and Transformers
  • Complementary to VICReg (VICReg = loss-based, ContraNorm = architecture-based)
ContraNorm Formula:
h_norm = h - h.mean(dim=0) + momentum * (h - h_prev) * strength
Implicitly shatters representations by adding a contrastive-style uniformity pressure, forcing embeddings away from low-rank subspaces.

1.2 Multi-Task Loss Balancing (Dual-Balancing MTL, 2026)

Paper: Lin et al. (HKUST 2026) "Dual-balancing for multi-task learning"
Method: DB-MTL = Log Transform (loss balancing) + Max-Norm Gradient Normalization
Result: State-of-the-art on NYUv2, CityScapes, consistently outperforms GradNorm, IMTL, Nash-MTL

Key Insight: When loss scales differ by orders of magnitude (value: 1653 vs return: 210), the larger loss dominates gradients and silences smaller tasks.

Solution:

  1. Log Transform: Replace w * L with w * log(L + 1) → all losses on same scale
  2. Gradient Normalization: Normalize each task gradient to max_norm = max(||g_task||)
L_total = sum(w_k * log(L_k + 1))  # Loss-scale balancing
g_k_norm = g_k / ||g_k|| * max_norm  # Gradient-magnitude balancing

1.3 Gradient Surgery (PCGrad, Yu et al. NeurIPS 2020)

Problem: Task gradients can conflict (negative cosine similarity), causing destructive interference
Solution: If cos(g_i, g_j) < 0, project g_i onto normal plane of g_j
Effect: Removes conflicting components, preserves constructive directions

PCGrad Algorithm:

for each pair (i, j):
    if dot(g_i, g_j) < 0:  # Conflict detected
        g_i = g_i - (dot(g_i, g_j) / dot(g_j, g_j)) * g_j  # Project onto normal plane

When useful: Multi-task learning with high curvature + gradient magnitude differences → exactly our case (value/return/obs_type)

1.4 Financial GNN Best Practices (2026)

Key Findings:
  • GAPNet (arXiv 2602.00888): GNN performance highly sensitive to graph structure; task-specific graph learning > predefined graphs
  • Regime-Aware GNNs (Nature Humanities 2026): HMM-assisted dynamic graphs + learnable correlation layers outperform static adjacency
  • Multi-Source Fusion (PMC 9135987): Combining price + news + graph features >> single-source

Actionable Takeaway: Embeddings must be jointly trained with the prediction head (end-to-end), not frozen or pre-trained separately. Our concat_head architecture (price features + embeddings) is correct.

2. Proposed V61 Solution

2.1 Architecture Changes

  1. Add ContraNorm Layer after each GAT layer in HetTGN
    • Prevents dimensional collapse directly in the architecture
    • Zero parameters, negligible compute overhead
    • Momentum = 0.9, strength = 0.01 (standard settings from paper)
  2. Keep VICReg at 0.25
    • ContraNorm + VICReg are complementary (architecture + loss-based)
    • Together they provide stronger anti-collapse signal than either alone

2.2 Loss Balancing Changes

  1. Implement Log Loss Transformation (DB-MTL) 
    # Before: total = w_obs * L_obs + w_val * L_val + w_ret * L_ret + ...
# After:  total = w_obs * log(L_obs + 1) + w_val * log(L_val + 1) + ...
  2. Reduce value_weight: 0.3 → 0.1
    • Value loss was 8× larger than return loss in V60
    • Even with log transform, we want return to have comparable weight
  3. Keep return_weight: 1.0
    • Return is the primary financial signal
    • Log transform will prevent it from being silenced

2.3 Gradient Balancing Changes

  1. Implement PCGrad (Projecting Conflicting Gradients)
    • Apply after computing per-task gradients
    • Project conflicting gradients onto normal planes
    • Model-agnostic, applies during optimizer.step()
  2. Alternative: Max-Norm Gradient Normalization (simpler)
    • If PCGrad is too complex, use max-norm normalization from DB-MTL
    • Normalize each task gradient to max gradient norm
    • Easier to implement, nearly as effective

3.1 ContraNorm Layer (het_tgn.py)

class ContraNorm(nn.Module):
    """ContraNorm layer (Guo et al. 2023) to prevent dimensional collapse."""
    def __init__(self, momentum=0.9, strength=0.01):
        super().__init__()
        self.momentum = momentum
        self.strength = strength
        self.register_buffer('running_mean', None)
    
    def forward(self, h):
        if h.size(0) < 2:
            return h
        
        batch_mean = h.mean(dim=0, keepdim=True)
        h_centered = h - batch_mean
        
        if self.running_mean is None:
            self.running_mean = batch_mean.detach().clone()
        else:
            with torch.no_grad():
                self.running_mean = (self.momentum * self.running_mean + 
                                    (1 - self.momentum) * batch_mean.detach())
        
        # Contrastive uniformity term: push away from running mean
        uniformity = self.strength * (h - self.running_mean.detach())
        return h_centered + uniformity

3.3 PCGrad (trainer.py)

def _pcgrad_projection(task_grads):
    """Project conflicting gradients (Yu et al. NeurIPS 2020)."""
    n_tasks = len(task_grads)
    projected_grads = [g.clone() for g in task_grads]
    
    for i in range(n_tasks):
        for j in range(n_tasks):
            if i == j:
                continue
            g_i, g_j = projected_grads[i], task_grads[j]
            dot_ij = torch.dot(g_i, g_j)
            if dot_ij < 0:  # Conflict
                proj = (dot_ij / torch.dot(g_j, g_j).clamp(min=1e-8)) * g_j
                projected_grads[i] = g_i - proj
    
    return projected_grads
