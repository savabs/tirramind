1. Goal & Concept

The implied volatility surface is the primary repository of market expectations regarding future underlying price distributions. Point estimates of volatility are insufficient for robust option trading and portfolio hedging. We require:

  • SVI Parameterization (Stochastic Volatility Inspired): A smooth, stable parameterization of each implied variance smile (per maturity slice) that enforces structural consistency and is robust to overfitting.
  • SABR Stochastic Volatility Model: A model of volatility smiles driven by Hagan's asymptotic formula to capture local volatility dynamics, forward skew, and dynamics across maturities.
  • No-Arbitrage Constraints: Verification that our fitted surfaces are free of calendar arbitrage and butterfly arbitrage (by checking that Durrleman's local risk-neutral density function is positive everywhere).
  • GNN Node Feature Extraction: Decomposing the continuous surface into a vectorized, finite set of low-dimensional node features (ATM vol, skewness, curvature, term structure slope, SVI parameters) to condition GNN relational asset predictions.

2. Raw SVI Mathematical Formulation

Raw SVI parameterizes total implied variance $w(k; a, b, \rho, m, \sigma)$ for log-moneyness $k = \log(K/F)$ as:

w(k) = a + b * (rho * (k - m) + sqrt((k - m)^2 + sigma^2))

where:

  • a: Vertical translation (minimum variance level).
  • b: Slope of the asymptotes.
  • rho (ρ): Correlation between the asset price and volatility, determining the rotation/skewness.
  • m: Horizontal translation.
  • sigma (σ): Curvature parameter.

3. Durrleman's No-Butterfly-Arbitrage Condition

Butterfly arbitrage is present if and only if the risk-neutral density is negative. Under Durrleman's condition, the density $p(k)$ is positive if:

g(k) = (1 - k * w'(k) / (2 * w(k)))^2 - w'(k)^2 / 4 * (1 / w(k) + 1 / 4) + w''(k) / 2 >= 0

where $w'(k)$ and $w''(k)$ are the first and second derivatives of SVI total variance w.r.t log-moneyness $k$. We will implement analytical derivatives or use PyTorch autograd to evaluate $g(k)$ dynamically and output no-arbitrage flags.

4. SABR Stochastic Volatility Model (Hagan Approximation)

The SABR model represents the asset's forward rate $F_t$ and its volatility $\alpha_t$:

dF = alpha * F^beta * dW1
dalpha = nu * alpha * dW2

where $dW1 \cdot dW2 = \rho dt$. Hagan's formula for implied volatility $\sigma_{\text{SABR}}$ is:

sigma(K) = [alpha / ( (F * K)^((1-beta)/2) * (1 + (1-beta)^2/24 * log(F/K)^2) )] * (z / x(z)) * [1 + ( (1-beta)^2/24 * alpha^2/(F*K)^(1-beta) + rho*beta*nu*alpha/(4*(F*K)^((1-beta)/2)) + (2-3*rho^2)/24 * nu^2 ) * T]

where:

z = (nu / alpha) * (F * K)^((1-beta)/2) * log(F/K)
x(z) = log( (sqrt(1 - 2*rho*z + z^2) + z - rho) / (1 - rho) )

5. GNN Node Features

To interface the continuous volatility surface with GNN instrument nodes, we extract:

  • ATM Volatility: $\sigma_{\text{implied}}(k=0)$.
  • Skew (Skewness Slope): $\frac{\partial \sigma_{\text{implied}}}{\partial k}(k=0)$.
  • Curvature: $\frac{\partial^2 \sigma_{\text{implied}}}{\partial k^2}(k=0)$.
  • Term Structure Slope: The difference between long-term and short-term ATM volatility.
  • SVI Params: $[a, b, \rho, m, \sigma]$.
