## Creating the Upload Zip

### CRITICAL: The `-j` Flag BREAKS the Upload

The notebook's `find_data_root()` function looks for a directory that contains **both**:
- `pipeline.db` (file)
- `checkpoints/` (subfolder)

**If you use `-j` (junk paths), the folder structure is stripped and `find_data_root()` will fail.**

### Correct Zip Command (preserves folder structure)

```bash
cd /home/becmachlean/2024/projects/tirramind_v1

zip tirramind_data_upload.zip \
  .tirra_pipeline/pipeline.db \
  .tirra_pipeline/checkpoints/epoch_001.pt \
  .tirra_pipeline/checkpoints/epoch_002.pt \
  .tirra_pipeline/checkpoints/epoch_003.pt \
  .tirra_pipeline/checkpoints/epoch_004.pt \
  .tirra_pipeline/checkpoints/epoch_005.pt
  # add more epoch_XXX.pt lines as training progresses
```

Resulting zip structure (what Kaggle sees after extraction):
```
.tirra_pipeline/
  pipeline.db
  checkpoints/
    epoch_001.pt
    epoch_002.pt
    ...
```

### Wrong (FLAT — will FAIL silently)
```bash
zip -j ...   # ← -j strips all paths — DO NOT USE
```

## Notebook Cell Map

| Cell # | Type | Purpose |
|---|---|---|
| 1 | Markdown | Title + instructions (update this when epoch target changes) |
| 2 | Python | GPU / device detection → sets `DEVICE` |
| 3 | Python | System deps check |
| 4 | Python | Diagnostics |
| 5 | Python | **Setup**: git clone code + copy data from `tirramind-data` dataset |
| 6 | Python | Verify environment |
| 7 | Python | Torch/CUDA check |
| 8 | Python | Patch imports (lazy APScheduler) |
| 9 | Python | Verify DB + checkpoints → sets `RESUME_EPOCH` |
| 10 | Markdown | Training info (update `--epochs` and resume epoch here) |
| 11 | Python | **Run `retrain_gnn.py`** subprocess |
| 12 | Markdown | Training complete |
| 13 | Python | Copy new epoch_*.pt + gnn_model.pt to `/kaggle/working/` for download |
| 14 | Markdown | Download instructions (update epoch numbers here) |

### What to update in the notebook before each new run

- **Cell 1**: change "resumes from epoch_XXX.pt and completes epochs N–M"
- **Cell 11**: `--epochs` flag = total epochs target (not delta); `--resume` = auto-detected from checkpoints
- **Cell 13**: `if epoch_num > N` — set N = last epoch already downloaded
- **Cell 14**: update the list of epoch files to download

## Training Command (retrain_gnn.py)

```bash
python scripts/retrain_gnn.py \
  --epochs 20 \              # total epochs to train to (not delta); currently at 10
  --hidden-dim 64 \          # NOTE: existing checkpoints use hidden=64, NOT 128
  --num-layers 2 \
  --lr 1e-3 \
  --backup \
  --window-size 604800 \     # 7 days in seconds
  --gdelt-frac 0.05 \        # keep 5% of GDELT — prevents OOM (92% of DB is GDELT)
  --max-windows 200 \        # cap to last 200 windows — bounds peak RAM
  --device cuda \            # Kaggle T4/P100 — always use cuda
  --skip-eval \
  --checkpoint-dir .tirra_pipeline/checkpoints \
  --resume 10                # auto-detected by notebook from latest checkpoint
```

### Phase 41 note (return_pred_head)
The model now has a `return_pred_head` for instrument log_return supervision.
Existing epoch_001–010 checkpoints do NOT have this head. The trainer loads with
`strict=False` so resume from epoch_010 works — `return_pred_head` weights will
be randomly initialized and trained from epoch 11 onward.

The `--resume N` flag is set automatically by the notebook's Cell 9 — it finds the highest `epoch_*.pt` file.

## Multi-Hypothesis Parallel Training (Phase 42+)

**Kaggle free tier: 2 concurrent GPU sessions.** Run 2 notebooks simultaneously
and queue the next pair while those run (~5–8h per pair on T4).

### New CLI Flags Added (Phase 43)

| Flag | Default | Purpose |
|---|---|---|
| `--num-heads N` | 2 | HGT attention heads (must divide `--hidden-dim`) |
| `--direction-loss` | off | Add BCE direction (sign) loss alongside ListNet |
| `--direction-loss-weight W` | 0.3 | Weight for direction BCE when `--direction-loss` active |

### Evaluation After Each Hypothesis Run


Primary metric: ICIR > 0.25 = directional signal. > 0.40 = strong signal.
Winning architecture from H-D/H-G/H-H advances to replace H-A as the new baseline.
