North star (one sentence): TirraMind is an advanced self-improving agent company whose core asset is a learned cross-domain entity embedding space ℰ — unified intelligence over heterogeneous reality. Markets are playground #1 (fast scoring, adversarial, monetizable readouts). The commercial end state is outcome-shaped intelligence (probability updates, ghost-pattern alerts, regime state) — not a trading bot, not a copilot, not a data API wrapper.

1. What we are building (the asset)

1.1 The embedding space ℰ

  • ℰ = persistent, time-evolving entity embeddings from HetTGN + memory over a heterogeneous graph.
  • Entity state h_i(t) encodes latent condition; prices, spreads, and P&L are readouts, not the definition of intelligence.
  • Moat: fusion of sensors nobody else jointly models — physical (L0) + behavioral (L1) + informational (L2) → price consequences (L3).
  • Quality bar: belief Δ, alignment losses, episode retrieval, niche event prediction — not vanity accuracy on a single head.

1.2 Ghost patterns (the economic mechanism)

A ghost pattern is a joint trajectory anomaly across entities and domains — a chain invisible to any single-instrument feature or single data vendor.

Physical world (L0)  →  Country / sector events (L1)  →  Instrument readout (L2/L3)
         ↑________________ graph message passing / ℰ ________________↑
  • Example: GDELT supply disruption → energy sector node stress → producer-country capital outflow → CFTC positioning velocity spike → crude lag weeks later.
  • Detection stack (target): graph path templates → embedding trajectory anomaly (TDC-AE) → GNN readout heads with walk-forward proof.
  • See [[ghost_pattern_graph_audit]], [[machine_intelligence_architecture]], [[LESSONS]] R-ghost sections.

4. Build order (non-negotiable)

  1. Layer A — Raw intelligence: sensor density, graph topology, ℰ training, ghost-pattern detection, honest baselines.
  2. Layer B — Packaging: briefs, alerts, archives, APIs — only after readouts are defensible.
  3. Layer C — Scale: firm delivery, platform, multi-playground transfer.
Anti-pattern: Shipping a fancy wrapper (API fetch + chart + Substack) before cross-domain ghost signal exists. Near-term income must still be intelligence-shaped — see [[ghost_pattern_income_plan]].

5. Success horizons

Year 1–2 (proof)

  • ≥1 micro-playground with public ghost-pattern track record (chain alerts, not z-scores alone).
  • Two-stage GNN or trajectory detector beats honest momentum baseline on Phase 41b gate (IC > 0.03, t > 2).
  • Daily pipeline running — L0 sensors populated for chosen micro-niches.
  • Earnable income from niche intelligence products (not venture scale).

Year 3–5 (compound)

  • ℰ stable across regime shifts; continual learning without catastrophic forget.
  • Multiple micro-playgrounds on same ℰ machinery (new sensors + readout head, not new company).
  • B2B: prop/quant monitored ghost-pattern feeds with audited walk-forward stats.
  • Agent loop closes: perceive → represent → act → learn with measurable belief Δ.

Year 5–10 (end state)

  • Outward product: probability distributions and decision advantage over Layers 0–3 — physical → behavioral → information → prices.
  • Transfer: same ℰ + agent architecture generalizes beyond markets (new playground, same stack).
  • Services-as-software at scale: customers buy outcomes; models are replaceable internals ([[predictive_platform_positioning]]).
  • Optional: proprietary capital deployment — only after years of OOS proof, not as identity.

6. Explicit non-goals (do not become this)

  • A quant fund hiring discretionary sector analysts per vertical.
  • A Bloomberg alternative or commodity data reseller.
  • An “AI newsletter” or sentiment product (fear/greed, narrative ML).
  • A copilot / ChatGPT wrapper over public APIs.
  • A generic embedding API — customers buy readouts, not vectors.
  • A Palantir clone before ℰ works on at least one playground.

7. Edge thesis (why this can win)

Unconventional observation × SOTA math × living system architecture.

  • Cheapest data is often most valuable — nobody else looks (CFTC + AIS + drought + country fusion, not Terminal headlines).
  • Math on common data is commoditized; math on unique joint data is the moat.
  • Hand-code schemas and invariants; learn ambiguous relations, scoring, and latent structure ([[agent_playground_doctrine]] rule #9).
  • Signal Depth Doctrine: L1 aggregate → L2 entity → L3 cross-entity combinations ([[SCHEMA]]).

9. Decision filter (all work)

Before prioritizing any work, ask ([[agent_playground_doctrine]] §7):

  1. Does this improve ℰ or the agent loop?
  2. Does this strengthen systems truth?
  3. Does this advance N1+N4 readouts or microstructure math?
  4. Is this sentiment/narrative? → reject or reframe as measurable events.
  5. Is this a playground-only hack with no transfer to general intelligence?
