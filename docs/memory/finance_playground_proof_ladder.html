2. Three concrete benefits (MP-1 Atlantic energy)

Benefit A — Cross-domain state in one object (not four tabs)

Before: Analyst opens EIA petroleum status (inventory level/change), CFTC disaggregated (WTI-Physical mm net + weekly Δ), optional AIS/Baltic context, GDELT producer stress — and mentally stitches timing lags.

After: Agent emits one auditable record, e.g. template ais_eia_cftc:

{
  "chain_template": "ais_eia_cftc",
  "nodes": [
    {"source": "energy_supply", "series": "crude_excl_spr", "z": -1.8, "period": "2026-05-29"},
    {"source": "cftc", "entity": "WTI-PHYSICAL", "metric": "mm_net", "z": -1.3, "report": "2026-06-02"}
  ],
  "readout_instrument": "CL=F",
  "issued_at": "2026-06-09T..."
}

Measurable: ≥2 domains in one alert (G1); every node has public URL + timestamp (G3).

Competitor gap: COTBase = positioning only. Kpler/AIS vendors = flows only. EIA = inventories only. No single product ships this joint state as a machine record.

Benefit B — Scenario flag before you need the narrative

Before: Desk reacts after Reuters headline or EIA surprise; scenario planning is ad hoc.

After: Agent flags named setups with falsifiers, e.g.:

  • Low inventory regime + specs not crowded long (physical tightness + positioning room)
  • Large weekly draw + NG positioning velocity extreme (Atlantic book composition)
  • Producer-country stress + WTI mm net below mean (geopolitical + positioning geometry)

Measurable: Alert archived before 2–5 session CL=F resolution; outcome appended to same file + scorecard row.

Not claimed: “Buy CL=F.” Claimed: tighten scenario set — hedgers know which risks to rehearse.

Benefit C — Reproducible engine, not a one-off analyst note

Before: “Trust me, I saw it in the data” — no pre-registration, no versioned pipeline.

After:

make ghost-pattern-daily   # same inputs → same scan logic
# → alerts/*.json + scorecard.md updated

Measurable: Re-run on same DB date → same template match (deterministic Phase A chains). Public archive: github.com/dry-clean/tirramind-ghost-archive.

Agent SKU angle: Buyer gets the runtime + templates + eval scripts, not a PDF brief.
