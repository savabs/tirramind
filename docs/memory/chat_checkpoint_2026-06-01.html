PART 4: CORE QUANT PROBLEMS INCURRED & NUMERICAL RESOLUTIONS

1. The Complex Log "Branch Cut" Issue in Heston (M3)

  • The Problem: The Heston characteristic function involves a complex logarithm of the form $\ln(d)$ or $\ln(1-g e^{-d T})$. In standard formulations, the complex logarithm has a "branch cut" along the negative real axis. As the integration variable $u$ increases, the complex argument crosses this cut, causing a jump of $2\pi$ in the phase. This discontinuity breaks option pricing and results in completely incorrect (often negative or wildly fluctuating) prices and NaN gradients.
  • The Resolution: We adopted Albrecher's "Little Trap" formulation of the complex logarithm. By choosing the stable formulation:
    d = sqrt((kappa - 1j * rho * xi * u)**2 + xi**2 * (u**2 + 1j * u))
    g = (kappa - 1j * rho * xi * u - d) / (kappa - 1j * rho * xi * u + d)
    and performing logarithmic calculations with terms that do not cross the branch cuts, we guaranteed mathematical continuity and infinitely differentiable pathways across all parameter ranges.

2. Martingale Drift in Merton Jump-Diffusion (M3)

  • The Problem: Jumps introduce a discontinuous shift in asset prices. Under risk-neutral pricing, the underlying asset's expected rate of return must equal the risk-free rate $r$. If we simply add jumps, the asset will have a drift of $r + \text{average jump return}$, allowing arbitrage.
  • The Resolution: We derived and applied the exact risk-neutral martingale drift correction term inside the characteristic function:
    drift_correction = -0.5 * (sigma**2) * T - lambda_param * (exp(mu_J + 0.5 * sigma_J**2) - 1.0) * T
    This corrects for the expected jump-size impact, guaranteeing that discounted stock prices are true martingales.

3. SABR Hagan ATM Singularity (M5)

  • The Problem: In Hagan's asymptotic implied volatility expansion, the ratio $z / \chi(z)$ has a $0/0$ division-by-zero singularity when the strike $K$ is exactly equal to the forward price $F$ (at-the-money options). In floating-point arithmetic, computing this directly returns NaN, breaking backpropagation and calibration gradients.
  • The Resolution: We implemented a second-order Taylor series expansion guard around $z=0$:
    ratio_taylor = 1.0 - 0.5 * rho * z + ((2.0 - 3.0 * rho**2) / 12.0) * z**2
    If $|z| < 1e-4$, the Taylor expansion is used, ensuring smooth, differentiable, and stable implied volatility and Greek calculation around the ATM strike.

4. BLP Volterra Path Explosion in Rough Bergomi (M6)

  • The Problem: The power-law kernel $(t-s)^{H-1/2}$ has a singularity at $s = t$. In our initial implementation of Bennedsen-Lunde-Pakkanen (BLP) hybrid simulation, paths exploded to inf or collapsed to 0 within 5 steps.
  • The Resolution: Discovered that both the local part $Y^L$ and the history weights $b_j$ must scale with $dt^H$ rather than $dt^{H-1/2}$. Correcting this scaling resolved the numerical explosion, yielding stable, beautiful, and realistic rough variance paths.

PART 5: THE SIGNAL DEPTH DOCTRINE & THE DIFFERENTIABILITY INVARIANT

1. The Signal Depth Doctrine (L1 vs L2 vs L3)

Under the project's Signal Depth Doctrine, we design for L2 (entity-level) feature extraction from day one. In our volatility surface implementation, rather than using market-wide aggregate indices (L1), we construct independent, fitted SVI surfaces for each individual asset. SVI parameter slices and analytical metrics (`atm_vol`, `skew`, `curvature`, `term_slope`) are treated as L2 local node features for each asset in the HGT graph. Aggregate market conditioning (e.g., VIX, aggregate volume) acts as L1 graph-level inputs, but the local entity-level resolution is the primary driver of alpha.

2. The Differentiability Invariant (No Numpy Jumps)

A core invariant across Layer 2 (Feature Engineering) is strict PyTorch differentiability. The forward passes of all models (including SDE simulation, Fourier-COS pricing, SABR pricing, SVI fitting, and bilinear total variance interpolation) are written entirely in native PyTorch tensors and operators.

CRITICAL RUNTIME WARNING: Subsequent agents MUST NEVER introduce non-differentiable operations (such as converting to NumPy arrays via .numpy(), using standard python control flow/indexing on parameters, sorting, or using libraries like scipy or cvxpy within the forward pathways). Doing so breaks the PyTorch autograd graph, severing the gradient highway. Maintaining this gradient highway is what allows Layer 5 portfolio losses to propagate all the way back to SVI parameters in Layer 2, enabling joint end-to-end learning.

PART 6: EXACT ANALYTICAL GNN NODE FEATURE DERIVATIONS

To prevent numerical instability in GNN feature extraction, we derived the exact analytical derivatives of the SVI total variance function rather than using finite-difference approximations.

1. SVI Total Variance & First Derivative ($w'$)

The Gatheral SVI total variance function is defined as: $$w(k) = a + b \left( \rho (k - m) + \sqrt{(k - m)^2 + \sigma^2} \right)$$ Letting $h = \sqrt{(k-m)^2 + \sigma^2}$, the first derivative of total variance with respect to log-moneyness $k$ is: $$w'(k) = \frac{\partial w}{\partial k} = b \left( \rho + \frac{k - m}{h} \right)$$

2. SVI Second Derivative ($w''$)

Differentiating again, we get the second derivative of SVI total variance: $$w''(k) = \frac{\partial^2 w}{\partial k^2} = b \left( \frac{h - (k - m) \cdot \frac{k-m}{h}}{h^2} \right) = b \left( \frac{h^2 - (k - m)^2}{h^3} \right) = b \left( \frac{\sigma^2}{h^3} \right)$$

3. Conversion to Implied Volatility Derivatives ($\sigma'$ and $\sigma''$)

Implied volatility $\sigma(k)$ is related to total variance by: $$\sigma(k) = \sqrt{\frac{w(k)}{T}} \implies w(k) = T \sigma^2(k)$$ Differentiating both sides with respect to $k$: $$w'(k) = 2 T \sigma(k) \sigma'(k) \implies \sigma'(k) = \frac{w'(k)}{2 T \sigma(k)}$$ This represents the ATM Volatility Skew.

Differentiating a second time: $$w''(k) = 2 T \left( (\sigma'(k))^2 + \sigma(k) \sigma''(k) \right)$$ Solving for $\sigma''(k)$: $$\sigma''(k) = \frac{w''(k) - 2 T (\sigma'(k))^2}{2 T \sigma(k)} = \frac{w''(k) - 2 T \left( \frac{w'(k)}{2 T \sigma(k)} \right)^2}{2 T \sigma(k)} = \frac{2 w(k) w''(k) - (w'(k))^2}{4 T^2 \sigma^3(k)}$$ This represents the ATM Smile Curvature.
