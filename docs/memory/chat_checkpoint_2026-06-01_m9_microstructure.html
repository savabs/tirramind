M9 Components Implemented

M9.1: Order Flow Imbalance (OFI)

  • Class: OrderFlowImbalance
  • Methods: compute_ofi_trade_tape(), compute_ofi_zscore()
  • Algorithm: BVC-style volume classification using normal CDF of price changes
  • Tests: Sign correctness, z-score normalization, gradient flow

M9.2: VPIN (Volume-Synchronized Probability of Informed Trading)

  • Class: VPINCalculator
  • Methods: bucket_trades(), classify_buckets_bvc(), compute_vpin()
  • Algorithm: Equal-volume bucketing + BVC classification + rolling imbalance
  • Tests: Balanced/imbalanced buckets, gradient flow

M9.4: Bid-Ask Spread Estimation

  • Class: SpreadEstimator
  • Methods: corwin_schultz(), roll_measure()
  • Algorithm: Corwin-Schultz (CSD variant) from daily OHLC, Roll from return autocovariance
  • Tests: Synthetic spread recovery, gradient flow, numerical stability

M9.5: Kyle's Lambda (Price Impact)

  • Class: KyleLambdaEstimator (not nn.Module — uses NumPy OLS)
  • Methods: estimate_lambda()
  • Algorithm: Rolling 30-day window OLS: ΔP = α + λQ + ε
  • Tests: Synthetic price impact recovery, zero volume edge case

Unified Feature Extractor

  • Class: MicrostructureFeatureExtractor
  • Features: 11 dimensions per instrument:
    • spread_cs (1)
    • spread_roll (1)
    • ofi_zscore (1)
    • vpin (1)
    • vpin_regime (3) — one-hot [normal, elevated, extreme]
    • kyle_lambda (1)
    • lambda_regime (3) — one-hot [liquid, normal, illiquid]
