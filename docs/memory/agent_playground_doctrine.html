Canonical Doctrine: Advanced Agent Company

Status: Canonical owner for company identity, ML-first R&D posture, market playground, and niche selection process.
Effective: 2026-06-01 (commercial SKU revised 2026-06-09)
Supersedes: Any doc that implies TirraMind is a quant fund, a trading-newsletter company, or a “sell alpha / briefs” shop. Near-term trading GTM superseded by [[0003-agents-as-sku]].

One sentence: TirraMind is a low-level self-improving agent company — we sell agent runtimes (perceive → represent → act → learn), not trade calls; finance is playground #1 (rich sensors, fast falsification); the core asset is the engine (pipeline + ℰ + eval harness + tool loop), not P&L or newsletters.

3. ML-first vs quant-finance-first

  • Primary R&D: Which objectives, architectures, and data make ℰ predictive and stable across regime shifts?
  • Quant finance: Encoded once in agent/quant/ as differentiable invariants (SDE, surfaces, CVaR, copulas) and evaluation economics (costs, horizons, baselines).
  • Hiring bias: Graph/temporal ML, RL, representation learning, systems — plus a small senior quant core for constraints, not an army of sector analysts per vertical.
  • Expansion: New vertical = new sensors + edges + readout head on the same ℰ machinery, not a new firm per sector.

4. The embedding space ℰ (raw intelligence)

ℰ = persistent, time-evolving entity embeddings from HetTGN + memory over the heterogeneous graph. It is the internal world-state representation.

  • State, not price: h_i encodes latent condition of entity i; returns and P&L are readouts.
  • Moat: Cross-domain fusion (positioning + physical + behavioral + country) in one geometry — see [[world_state_prediction_methodology]].
  • Quality metrics: Belief Δ, alignment losses, episode retrieval, niche-specific event prediction — not only return IC.
  • Math stack (M1–M7): Physics of readouts and future end-to-end gradients into Layer 2 — not the definition of intelligence.

5. Markets as playground #1

Markets are the first scoring environment for the agent: partially observable, adversarial, non-stationary, rich public sensors, fast feedback, monetizable readouts.

  • Playground teaches: multimodal fusion, latent state, regime change, sparse reward, risk-aware action.
  • Success on playground ≠ “beat SPY once”; it means ℰ + readouts improve on auditable, out-of-sample tasks.
  • Build order: raw intelligence (Layer A — fusion, ℰ, microstructure math) before UI/GTM (briefs, Substack, archives). Packaging is Layer B and is explicitly deferred until ℰ probes pass.

6a. Mathematical field doctrine (NOT sentiment)

Banned as primary edge: sentiment indices, fear/greed, bullish/bearish copy, narrative ML, social hype. We compete like a quant desk: observables, invariants, regimes, information theory, microstructure math.

Use instead: σ and percentiles; BOCPD/HMM regimes; transfer entropy; positioning z-scores; vol surface geometry (M5/M6); OFI/VPIN/Kyle λ (M9); copulas and tail dependence. External copy cites data sources, not “AI sentiment.”

  2. Playground proves it — finance tasks pass internal gates (beat baselines on defined metrics)

6c. Finance as playground (kept, not sold)

Markets stay playground #1 because they offer:

  • Rich public sensors — prices, positioning, physical, geopolitical, flows
  • Fast falsification — held-out IC, walk-forward, scenario resolution
  • Adversarial non-stationarity — stresses continual learning and regime handling
  • Economic readouts — optional P&L sims to score agent actions, not to promise fund returns

Founder does not need to become a derivatives expert to build the agent. Finance literacy required = enough to wire sensors, labels, and eval economics in agent/quant/ — not desk storytelling.

6d. Agent loop (canonical architecture)

PERCEIVE  — DAG + tools → entity_observations (L0/L1/L2)
REPRESENT — graph build → HetTGN / ℰ snapshots
DETECT    — ghost chains, changepoints, rankers (structure flags)
ACT       — tool calls, alerts, exports (no mandatory trade execution)
LEARN     — logged outcomes → SSL / ranker / policy updates

Every feature must strengthen this loop. If it only decorates a dashboard, reject it.

6e. Unified intelligence (internal, not the SKU)

ℰ and cross-domain fusion are inside the agent. Buyers buy capability (“an agent that maintains Atlantic energy world-state and flags cross-domain anomalies”), not embedding dumps. Vectors may be exported for integrators later — not year-1 SKU.

7. Decision filter for all work

Before shipping or prioritizing work, ask:

  1. Does this improve the agent loop (perceive → represent → detect → act → learn)?
  2. Does this strengthen systems truth (tests, pipeline, reproducible eval artifacts)?
  3. Does this move us toward a deployable agent runtime, not a one-off notebook?
  4. Are we building playground proof on finance, or accidentally building a trading product?
  5. Is this sentiment/narrative GTM? If yes, reject ([[0002-ghost-pattern-gtm-pause]]).
  6. Would a systems engineer respect the code at 2am (Carmack test)?
