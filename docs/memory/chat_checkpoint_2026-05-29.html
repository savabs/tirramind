2. Key Discoveries & Diagnostic Breakthroughs

The F-09 Gradient Dead Zone (Zero-Init Bug)

The Problem: The trained 90-epoch checkpoint (V42) was generating +nan IC on evaluation.
The Root Cause: Direct weight inspection revealed that the output layer of the return predictor (return_pred_head.4.weight) was exactly 0.0 with zero variance. Because it was zero-initialized, the backpropagated gradients back into the GNN backbone were exactly zero: 
dL/d_hidden = dL/d_scores @ weight_last.T = dL/d_scores @ zeros = 0
This severed the GNN backbone from return training, freezing the weights at zero.

The Dims and Shape Alignment

The GNN state-dict loader on Kaggle crashed on shape mismatches due to inconsistent hyperparameter configurations. We aligned and confirmed the exact checkpoint tensor shapes:

  • hidden_dim = 128
  • memory_dim = 128
  • time_dim = 16
  • message_dim = 128 (giving a GRU input size of 144)
