Spec: Playground Niche Competition

Goal: Select playground #1’s commercial and evaluation niche by evidence, not narrative. The agent architecture stays general; the niche defines hero entities, hero readouts, and first GTM.

Non-goals

  • Do not freeze the global sensor surface to one sector.
  • Do not block engineering that helps all candidates (ℰ, pipeline, alignment).
  • Do not commit to a niche in marketing until the competition exit gate passes.

Process

  1. Baseline scorecard — per niche, same eval window (e.g. 26-week walk-forward where applicable).
  2. ℰ probes — 2–3 tasks per niche (e.g. CFTC regime shift, supply-stress episode retrieval, vol breakout).
  3. Readout prototype — minimal external-facing signal type + public archive entry format.
  4. Timebox: 4–6 weeks parallel exploration; weekly score update in checkpoint.
  5. Exit gate: Winner = highest weighted total + founder sign-off; document in [[agent_playground_doctrine]] and next checkpoint.
