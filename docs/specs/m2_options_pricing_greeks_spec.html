1. Overview

This specification details the code layout, numerical safeguards, implementation interfaces, and verification plans for the M2 Options Pricing & Greeks module. It covers vectorized Black-Scholes European pricing, automatic differentiation (autograd) Greeks, implied volatility solving via robust, differentiable Newton-Raphson iterations, and analytic American pricing under the Barone-Adesi Whaley framework.

2. Interface Requirements

All logic will be housed in agent/quant/options.py. Code must support multi-dimensional PyTorch tensors (e.g. 1D, 2D, or higher) and run seamlessly on both CPU and GPU (using PyTorch's native device dispatching).

3. Numerical Stability & Safeguards

To prevent NaN gradients under extreme or boundary conditions, we define the following constraints:

  • Time-to-maturity (\(T\)): Bound to a safe minimum of 1e-5 (roughly 5 minutes of a year).
  • Volatility (\(\sigma\)): Bound to a safe minimum of 1e-4 (0.01% vol) to prevent division by zero in \(d_1\).
  • Spot Price (\(S\)) and Strike (\(K\)): Bound to a safe minimum of 1e-6.
  • Cumulative Normal Distribution \(N(x)\): Implemented as 0.5 * (1 + torch.erf(x / math.sqrt(2))) which is numerically stable and has standard gradients.

4. Testing & Verification

We must enforce the following validation tests in tests/test_options.py:

  1. Smoke Test: European pricing matches standard Black-Scholes calculators for basic call/put options.
  2. Greeks Verification: Verify that automatic gradients computed via torch.autograd.grad match the analytical Greeks formulas to a tolerance of 1e-5.
  3. Implied Vol Flow: Verify that solved implied volatilities can be differentiated with respect to the input option prices.
  4. American Pricing boundary: Verify that American call prices are strictly greater than or equal to their European counterparts, particularly when dividend yields are high.
  5. GPU Compatibility: Confirm that pricing and autograd Greeks work properly on CUDA if available.
