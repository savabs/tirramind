Spec: GNN Two-Stage Pipeline (Phase B)

Research: [[gnn_architecture_overhaul]]  |  Task: [[gnn_architecture_overhaul_task]]

Gate: Phase A full baseline — Momentum-Rank IC=+0.074, t=2.0 PASS on canonical 21d labels.

Goal

Decouple representation learning from return prediction. Stage 1 trains HetTGN on self-supervised objectives only; Stage 2 fits a cross-sectional ranker on frozen embeddings against canonical forward returns (or momentum residual).

Stage 1 — Self-supervised HetTGN

  • Losses: obs_type CE + link prediction + time_delta (existing MTL heads minus return/CSRC)
  • return_weight=0, use_csrc_loss=False, use_concat_head=False
  • Training config mirrors V52 sampling: gdelt_frac=0.05, max_windows=200
  • Export: per-fold instrument embeddings ℰ ∈ ℝN×d at each walk-forward cutoff

Stage 2 — Cross-sectional ranker

  • Input: Stage-1 embeddings + optional raw price block (momentum feature index 0)
  • Model: Ridge (default) → RankNet if Ridge fails gate
  • Target: canonical 21d forward simple return via forward_return_vector_for_date()
  • Eval: same purged walk-forward as honest_baseline_audit.py (IC-only, 40 folds)
  • Primary strategy name: Stage2-RidgeRanker

Exit gate (unchanged)

Mean IC > 0.03 and t-stat > 2.0 on 40-fold purged walk-forward.

Implementation steps

  1. B.1 — Notebook config preset phase50_stage1_ssl (zero return weights)
  2. B.2 — scripts/export_gnn_embeddings.py — dump ℰ per fold date
  3. B.3 — scripts/stage2_ranker_eval.py — Ridge walk-forward on exported ℰ
  4. B.4 — Compare Stage2 vs Momentum-Rank baseline on same folds
