Spec: GNN Architecture Overhaul — Phase A Honest Baselines

Research: [[gnn_architecture_overhaul]]

Goal

Before any new GNN architecture work, run a unified honest-baseline audit that answers:

  1. What is the post-backfill forward-return label distribution? (H1)
  2. What IC do raw price features achieve with purged walk-forward Ridge? (ceiling without GNN)
  3. What IC does a single momentum factor achieve? (classical sanity check)
  4. Does frozen GNN ℰ beat raw features on the same folds? (graph value-add test)

Deliverable

scripts/honest_baseline_audit.py — single entry point, JSON output, gate verdict.

Implementation steps

A.1 — Label distribution audit

  • Load all observations via GraphBuilder.prefetch_observations()
  • Call _build_forward_return_lookup(obs, horizon_days=21)
  • Log: n, mean, std, min, max, pct_finite, pct_zero
  • Also log daily log_return cross-section std (for comparison)

A.2 — RawPrice-PurgedRanker strategy

  • Reuse phase40 walk-forward constants: min_train=252, test=21, step=21 (smoke: 126/21/21, last 400d)
  • Per fold: build instrument price features (dims BASE_FEAT_DIM:BASE_FEAT_DIM+PRICE_FEAT_DIM) at fold cutoff via build_from_cached
  • Fit Ridge(alpha) on train-fold samples only (same logic as GNNFoldPurgedRankerStrategy)
  • Score test fold; compute Spearman IC vs 21d forward return

A.3 — Momentum-Rank strategy

  • Rank instruments by momentum feature (price block index 0 = 21d momentum)
  • Softmax rank → weights; compute fold IC

A.4 — GNN-PurgedRanker (optional, --checkpoint)

  • Reuse existing GNNFoldPurgedRankerStrategy from phase40_gnn_backtest.py
  • Default checkpoint: latest V72 epoch weights if available

A.5 — Gate report + JSON output

  • Write .tirra_pipeline/honest_baseline_audit.json
  • Gate: mean IC > 0.03 AND t > 2.0 per strategy
  • Emit recommendation: DATA_FIX | TWO_STAGE | CONTINUE_TUNING (should never be last)
