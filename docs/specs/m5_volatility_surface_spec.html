2. API Specifications

2.1 SVIParameterization (Gatheral 2014)

This class encapsulates Raw SVI curves per maturity slice, with fitting capabilities via gradient descent and no-arbitrage checks.

class SVIParameterization(nn.Module):
    def __init__(self, a: float, b: float, rho: float, m: float, sigma: float, learnable: bool = True)
    def total_variance(self, k: torch.Tensor) -> torch.Tensor
    def implied_volatility(self, k: torch.Tensor, T: float) -> torch.Tensor
    def fit(self, k_market: torch.Tensor, w_market: torch.Tensor, lr: float = 1e-2, epochs: int = 1000) -> float
    def check_butterfly_arbitrage(self, k: torch.Tensor) -> torch.Tensor # Returns Durrleman's g(k) density check

2.2 SABRModel (Hagan 2002)

This class implements the vectorized, fully differentiable SABR Hagan implied volatility approximation formula in PyTorch.

class SABRModel(nn.Module):
    def __init__(self, alpha: float, beta: float, rho: float, nu: float, learnable: bool = True)
    def forward(self, K: torch.Tensor, F: torch.Tensor, T: torch.Tensor) -> torch.Tensor # Hagan IV
    def fit(self, K_market: torch.Tensor, F: torch.Tensor, T: torch.Tensor, iv_market: torch.Tensor, lr: float = 1e-2, epochs: int = 1000) -> float

3. Numerical Stability Guards

  • SVI Boundaries: $b \ge 0$, $\rho \in [-0.999, 0.999]$, and $\sigma \ge 1e-4$. This must be enforced during optimization via parameter projection or clamping inside forward.
  • SABR Hagan Boundaries: $\alpha \ge 1e-4$, $\nu \ge 1e-4$, $\rho \in [-0.999, 0.999]$.
  • SABR $z / \chi(z)$ Singularity: When $z \rightarrow 0$ (near ATM), $z / \chi(z) \rightarrow 1$. We must implement a robust limit guard: torch.where(torch.abs(z) < 1e-4, 1.0 - 0.5 * rho * z, z / x_z) to prevent NaN division in backpropagation!
