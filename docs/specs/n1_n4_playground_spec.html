Spec: N1+N4 Playground

Status: Active (founder sign-off 2026-06-02)
Replaces: “N1 only + N4 as appendix” — now a single fused playground.

Playground SKU: Commodity/energy macro (N1) × sovereign/geopolitical state (N4) × microstructure at every scale — because micro-changes (flow, positioning increments, policy shocks, physical stress) decide macro outcomes before headlines do.

1. Identity: mathematical field, not sentiment

Banned as primary signals: sentiment scores, fear/greed indices, bullish/bearish narrative, “the market feels…”, LLM opinion, social hype. GDELT is event counts and entropy, not vibe.

Required framing (Jane Street / RenTech bar):

  • Observables: positioning (CFTC), flows, rates, vol geometry, order-flow statistics where data exists
  • Structure: regimes (HMM), changepoints (BOCPD), transfer entropy, copulas, rough vol, SDE dynamics
  • Micro: OFI, VPIN, Kyle λ, spread estimators, Hawkes intensities — M9 priority on [[math_stack_roadmap]]
  • Output language: σ, percentiles, half-life, impulse response — never mood words

3. Hero readouts (external product)

  1. Positioning extreme — CFTC z-score vs rolling window (commodity futures)
  2. Regime break — BOCPD/HMM on returns + vol; stated half-life
  3. Sovereign stress composite — country-node fusion (yields, flows, event rate) tied to a tradeable hook (FX, commodity, spread proxy)
  4. Microstructure alert — flow imbalance / toxicity spike when tick data available; else proxy via positioning velocity + vol-of-vol
  5. Cross-domain chain — one auditable path (e.g. country stress → positioning shift → futures regime) with source URLs

4. Engineering priorities (raw intelligence first)

Deferred (UI / GTM layer — later): weekly brief generator, Substack, signal-archive marketing site. See [[revenue_plan_2026-05-08]].

  1. Sensor density: backfill N1 L0 + N4 country tools into pipeline.db
  2. M9 microstructure in agent/quant/ → features into graph_builder (M9.6)
  3. Multi-timescale fusion: Δpositioning, changepoint/regime flags, GDELT event-rate buckets — learned inputs, not hand-waved copy
  4. ℰ quality: GNN train/eval on N1+N4 probes (CFTC regime, country stress propagation, micro alerts) — not Sharpe-only
  5. Alignment: downstream belief Δ / walk-forward tasks per [[gnn_downstream_alignment]]

  • Sentiment API as a product feature
  • Crypto-primary GTM (N3 deprioritized unless founder reverses)
  • Selling raw vectors / “embedding API”
