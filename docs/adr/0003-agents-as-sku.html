ADR-0003: Agents as SKU — Finance as Playground

Status: accepted
Date: 2026-06-09
Deciders: Founder
Extends: [[agent_playground_doctrine]] · Supersedes: trading-signal / brief-first GTM ([[ghost_pattern_income_plan]] commercial track, [[0002-ghost-pattern-gtm-pause]])

Decision: TirraMind sells agents (self-improving runtimes on domain playgrounds). Finance is playground #1 for proof, not the product we ship to customers as trade calls or newsletters.

Context

  • Founder identity: systems / ML / low-level agent builder (Carmack), not trader or salesperson (Simons + Substack).
  • Ghost-pattern brief GTM paused — product felt fake; no sales appetite; no trading capital.
  • Long-term vision unchanged: agent company, ℰ, playground #1 = markets.
  • Prior doctrine (§6b) said customers buy “readouts” — revised: buyers buy agent capability; readouts are optional outputs of a deployed agent, not the SKU.

Ideology (formulation)

Three layers — never confuse them

LayerWhat it isAnalogy
EnginePipeline, store, DAG, trainer, agent loop, eval harnessid Tech engine / Carmack runtime
PlaygroundFinance (MP-1…): sensors, ontology, tasks, benchmarksGame level that stress-tests the engine
ProductPackaged agent for a domain (deploy + prove + operate)Licensed engine + reference game

What we say publicly

  • Say: “We build self-improving agents on market playgrounds — ingest multi-domain data, maintain world state, detect structure, log outcomes, get better.”
  • Say: “Finance is our first arena because it’s measurable and brutal — not because we sell stock picks.”
  • Never say: “We called crude,” “alpha as a service,” “subscribe for trade alerts,” “our AI is bullish.”

Agent definition (minimum viable)

while running:
  observations = perceive(tools, dag)       # deterministic fetch
  state        = represent(graph, ℰ)        # learned + structured
  signals      = detect(chains, rankers)    # falsifiable flags
  actions      = act(tools, exports, log)   # no required brokerage
  learn        = update(memory, checkpoints) # from logged outcomes

Moat

Not one z-score. The closed loop: heterogeneous sensors → entity graph → temporal ℰ → cross-domain detectors → auditable outcomes → continual update. Competitors sell single-source dashboards or static models.

Money path (aligned with identity)

  1. Proof: reproducible benchmark beats baselines on playground tasks
  2. Package: deployable agent + docs + eval (B2B license, managed runtime, or infra hire)
  3. Optional: domain partner sells readouts; founder stays engine

Personal trading without capital is not year-1 monetization. Bridge income (contract ML/systems) is allowed without changing SKU.

Consequences

  • [[agent_playground_doctrine]] §6b–6e updated — canonical commercial wording
  • Priority work: agent loop hardening, B.4-style eval verdicts, not brief polish or X
  • Concrete benefits + proof pass lines: [[finance_playground_proof_ladder]]
  • Ghost archive = demo / training labels for detector module
  • New features must pass agent-loop decision filter (doctrine §7)
