ADR-0002: Ghost Pattern GTM Pause — Founder Role ML/Backend Only

Status: accepted
Date: 2026-06-09
Deciders: Founder

Canonical owner for ghost-pattern go-to-market status. All other docs link here; they do not restate the decision.

Context

[[ghost_pattern_income_plan]] defined a near-term income wedge: MP-1 Atlantic energy ghost chains → public archive → X audience → $29/mo paid tier. Phase 0–2 infrastructure shipped (scanner, archive, 3 alerts, scorecard, GitHub repo).

Founder assessment (2026-06-09):

  • Strong fit: math, ML, pipelines, anomaly detection code
  • Weak fit: deep energy derivatives domain voice, sales, convincing strangers, X audience building
  • Product confusion: briefs read as costume for a desk role the founder will not play

The bedroom-income path (~80% distribution, ~20% ML) is a role mismatch, not a technical blocker.

Decision

Pause all ghost-pattern GTM. Founder role = ML/backend only. No sales track.

Stopped (GTM)Continues (backend / research)
X posting, audience growth, paid tier ($29/mo)
Telegram/email paid alert pings
MP-2/MP-3/MP-4 commercial expansion

Chain scanner + archive + scorecard (honest public record)
Phase B embedding_snapshots when tied to [[long_term_vision]] GNN work
B2B white-label only if a domain partner appears (not pursued solo)

Output definition (revised): detector + auditable alert JSON + scorecard — not a sold intelligence brief. Existing publish briefs remain as historical demo artifacts.

Consequences

  • [[ghost_pattern_income_task]] → status paused; commercial steps cancelled
  • [[ghost_pattern_income_plan]] GTM sections remain historical; active execution follows this ADR
  • Public GitHub archive stays up as portfolio / reproducibility demo; no active promotion required
  • Primary energy returns to TirraMind core ML (GNN, ℰ, playground) per [[long_term_vision]]

Revisit when

Only if both: (1) a domain-credible partner owns distribution, or (2) n≥20 archived alerts with scorecard beating baseline and founder explicitly opts back into GTM.
